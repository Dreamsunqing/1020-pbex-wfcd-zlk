# 星际战甲上游资料工作台

把分散的官方、Plus、WFCD、Oracle 和 browse.wf 资料放在一个离线工作台中：查看 JSON、说明字段和中文映射、按规则合并实体与奖励关系、查询和导出本地图片，并浏览双服世界状态、使用面向玩家的资料库、查询 WM 公开订单、双语官方掉落表与仲裁日历。当前版本 **0.17.0**。

本项目先跑通 P3 离线数据流程，再讨论仓鼠互助洞 App 的在线分发。邮件、uniCloud／ECS 部署仍待后续处理；`<xxx>` 文本标记通过统一中间件展示，已有映射使用离线真实图标。

## 运行

在资料包目录安装 `package.json` 的依赖后，运行：

```sh
npm start
```

或者双击 `工具/打开工具箱.command`（Mac）／`工具/打开工具箱.cmd`（Windows），选择“启动工作台”。命令行工具需 Node.js 22.19+；维护 WFCD 图库还需 Python 3。已有应用 ZIP 可以独立启动，维护脚本需要完整项目和依赖。

## 玩家资料库

“世界状态”后的“资料库”随程序附带预构建离线数据，首次进入无需构建，按战甲、武器、同伴、Mod 等十二类浏览；提供联动筛选、中文／英文搜索、图片卡片、技能与制造关联、Mod 等级效果和遗物内容。雷达图放在详情侧栏，使用同类基础属性分位；支持深浅主题。维护及数据边界见 [玩家资料库](文档/深入/20-玩家资料库.md)。

## 目录

```text
世界状态上游/                原始文本资料，按来源区分
assets/content/wfcd/img/    WFCD 原图
assets/content/wfcd/        WFCD 目录、图名及 ID 索引
assets/content/official/img/ 官方原图，内容去重
assets/content/official/    官方 Manifest 和索引
工具/                      可以直接运行的命名入口
scripts/                   维护实现
src/core/                  数据、映射、合并、图片与文档核心
src/desktop/               Electron 主进程、隔离接口、后台
src/ui/                    页面和交互
文档/入门、深入、AI/        当前文档
文档/归档/                 历史过程、报告和版本说明
.workbench/                CLI 快照、合并仓库；桌面版另有独立用户目录
输出/                      手动运行工具的导出结果
```

开发维护的图库集中在本项目。原独立攻略图片工具已合并并删除；同机开发版和普通发布版共用 `assets/content`。普通应用 ZIP 含资料库精简数据与卡框、文本图标，不含大图库；跨电脑查看配图需携带图库目录，开发与世界状态字典维护还需原始资料；GitHub Release 另提供 Windows x64 `with-images.zip`，内含现有 WFCD、官方图库及索引，解压后自动发现。含图版不另含原始资料或个人缓存，详见 [含图库发布说明](文档/深入/12-含图库Windows发布.md)。
