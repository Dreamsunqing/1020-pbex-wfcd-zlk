星际战甲 · 攻略图片工具 v1.0.1

一、打开工具
1. 把整个压缩包解压到电脑上的一个文件夹。
2. 双击「攻略图片工具.exe」。不需要安装开发环境，也不需要联网。
3. 请保留附带文件，不要只把 exe 单独拿出来。移动时请移动整个文件夹。
适用系统：Windows 10 / 11，64 位（x64）。

二、找到图片
左侧选择分类，上方输入中文名或英文名。
支持部分名称、英文大小写不敏感、空格分开的多个关键词。
例如「迅发」「Acceltra」「acceltra prime」；部件也可用所属装备名称搜索。
没有中文翻译时显示英文名。「全部记录」包含暂无图片的条目。

三、复制与保存
点击图片，在右侧使用「复制图片」「保存原图」。
复制图片后，在支持图片粘贴的编辑器中按 Ctrl + V。
也可以分别复制中文名、英文名、中英名称。
预览棋盘格/浅色/深色背景仅用于查看，不会加到原图中。
原图有透明背景时，保存原图会保留透明通道。
编辑器对图片粘贴的支持有所不同；若粘贴效果不符，可先保存原图，再在编辑器中插入。

四、批量导出
勾选图片左上角的选择框，或勾选「选择本页可用图片」。
可跨页、跨分类选择；底部会显示已选数量。
点击「只看已选」检查所选素材。当前搜索与分类仍会参与筛选，必要时先清空搜索、切到全部分类。
在底部选择文件命名方式，点击「导出所选图片」，选择保存文件夹。
相同文件名自动添加编号，批量导出不会覆盖已有文件。
单张「保存原图」若选择已有文件，系统会询问是否替换。
导出时可点击「停止导出」；已经保存的文件会保留。

五、快捷操作
Ctrl + K：跳到搜索框。
Ctrl + C：打开图片详情后，在未选中文字时复制当前图片。
点击右侧大图可放大查看；滚轮可缩放；Esc 关闭大图或说明窗口。

六、数据更新与问题排查
界面底部显示数据版本。更新时使用维护者提供的新压缩包，重新完整解压。
工具没有在线更新、账号或服务器连接，离线即可运行。
「暂无图片」表示当前 WFCD 快照没有可确认对应的图片，仍可检索和复制名称。
敌人分类中，37 条记录提供同角色的幽魂外观、浮印头像或战甲外观参考；卡片标注「参考图」，详情说明来源，可点击查看来源条目。
参考图不等于该敌人或内部变体的独立原图；另有 601 条敌人记录暂无可靠对应。
点击「查看未对应条目」可查看缺图敌人。全部对应关系、排除的误配和缺图名单见随包 README.md。
逐条明细见 resources/content/enemy-images.csv，可用 Excel 打开。图片严格来自 WFCD 仓库。
图片打不开时，请检查是否完整解压，附带的 resources 文件夹是否保留。
如果 Windows 提示应用来源未知，这是未购买发布者签名的版本；请先核实压缩包来自可信维护者。
个人的预览背景、缩略图大小和命名偏好保存在当前电脑的用户目录，替换程序包不会清除这些偏好。

素材及名称来自 WFCD/warframe-items，游戏素材权益归原权利人。
