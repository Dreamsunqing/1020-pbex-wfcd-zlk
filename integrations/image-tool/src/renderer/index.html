三步，把图片用进攻略

  1. 找到素材

    输入中文或英文名称，也可以从左侧选择分类。多个关键词用空格分开；搜索部件时可输入所属装备的名称。

  2. 复制或保存

    点击图片，在右侧选择「复制图片」或「保存原图」。复制图片后，在支持图片粘贴的编辑器中按 Ctrl + V。

  3. 一次导出多张

    勾选图片左上角的选择框，点击底部「导出所选图片」。跨页、跨分类的选择都会保留；同名文件会自动编号。

图片随程序提供，无需联网。缺少中文翻译的条目会显示英文；「暂无图片」记录仍可复制名称。预览底色不会加入保存的原图。不同编辑器的图片粘贴效果可能不同，遇到问题可保存原图后插入。
