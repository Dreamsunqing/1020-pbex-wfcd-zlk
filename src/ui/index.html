本地计算 · UTC 排期

01 / WORLD CYCLES

世界周期

双衍王境情绪、山谷温度、平原昼夜与火卫二。顶部“刷新并查询”从官方接口获取世界状态；离线时使用已有基准。

02 / TESHIN

Teshin 周商品

按周轮换，周一 UTC 00:00 切换。

03 / THE CIRCUIT

普通／钢铁回廊

每周 3 个普通战甲、5 个钢铁之路武器选项。

04 / STEEL PATH INCURSIONS

钢铁之路每日突袭

按 UTC 日期查询缓存的 6 节点排期，显示节点、星球、任务与等级。

六个模块共用参考时间。默认当前时间；细分条件在各模块内调整后自动查询。

尚未读取世界状态。点击“刷新并查询”，或在周常模块中导入世界状态 JSON。
01 / BOUNTY CYCLE

赏金轮次

扎里曼、英择谛实验室与 1999 的节点、挑战、同伴及各档奖励。展开随机奖励查看物品、数量、概率与来源。

02 / LOCATION BOUNTIES

地区赏金

平原、山谷、火卫二各地区的赏金选项，使用 Cetus seed；保留任务原始路径。

03 / INVASION MISSIONS

入侵任务变化

每 15 分钟一轮，分别推算支援进攻方与防守方的任务。后续轮次假定该入侵继续存在。

04 / WEEKLY CONQUESTS

实验室／Hex 周常

整理参考时间内有效的周常任务，使用第二档难度的变体与风险，展示个人限制及名称转换；不外推下周。

按顶部参考时间记录采集时间；导入后重新查询全部六个模块。
05 / INVIGORATIONS

活化战甲

用户名区分大小写。Tenno 为可替换的示例名；输入目标周的上一周战甲，缺少历史时返回条件推算。

06 / ARBITRATION

仲裁排期

按缓存的逐小时排期查询，返回节点和任务类型。
