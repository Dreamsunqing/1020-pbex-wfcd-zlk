## 建议的阅读顺序

先读对应深入章节，再读 core 实现，最后读 worker handler 和页面调用。修改规则时确认 UI 和 CLI 都能指定同一份合同；修改图片路径时同时处理获取脚本、目录选择、索引读取、工具和文档。

2026-10-23 已恢复测试。启动与展示回归入口 scripts/check-presentation-ui.mjs，图库交互回归 scripts/check-unified-ui.mjs；二者都用独立临时用户目录。优先定点验证，不自动运行工具 06 扫描大图库。文本图标下载 scripts/fetch-text-icons.py；JSON 到 JS 的登记表生成 scripts/prepare-inline-tokens.mjs。

套装 Mod：`src/core/merge/mod-set-links.mjs` 建模，`src/core/mod-sets.mjs` 件数投影，`src/core/merge/service.mjs` 为所有入口生成同语言卡面元数据，`src/ui/images.js` 读取徽记，`card-art.js` 拼图。说明和边界见 [第 26 章](../深入/26-套装Mod关联效果与卡面.md)，定点验证 `scripts/check-mod-sets-ui.mjs`。
