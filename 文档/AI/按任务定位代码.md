# 按任务定位代码

这个表帮助 AI 和开发同事缩小阅读范围；每次改动仍以文件现状为准。

| 要改什么 | 优先读／改 | 联动注意 |
| --- | --- | --- |
| 上游来源和语言 | `config/default.json`、`src/core/config.mjs` | 默认配置和用户保存配置不是同一个文件 |
| 获取／导入／回滚 | `src/core/updater.mjs`、`store.mjs`、`src/cli.mjs` | current 切换、哈希和快照身份必须完整 |
| 文件分类与筛选 | `src/core/library.mjs`、`facets.mjs`、`src/ui/app.js` | 来源／类型／语言／物品类别多选 |
| 中文标题 | `src/core/preview-titles.mjs` | 只读；字典上下文；完整技能 ID 桥接 |
| 字段说明与结构视图 | `field-guide.mjs`、`json-structure.mjs` | 完整记录与去重后的字段结构不同 |
| 合并分类／字段 | `src/data/merge-full-contract.json`、`merge/rules.mjs`、`full-inputs.mjs`、`full-build.mjs` | 不以遍历顺序选值；保存候选证据 |
| 嵌套与技能强化 | `merge/nested.mjs`、`ability-links.mjs`、`service.mjs` | 实体、关系、徽章、来源与 UI 一并考虑 |
| 配方／奖励 | `merge/full-build.mjs`、`reward-context.mjs` | 普通静态奖励不负责确认实时轮次 |
| 实时赏金 | `oracle-bounties.mjs`、`oracle-rewards.mjs`、`oracle-data.mjs`、`oracle-state.mjs` | seed 和 rewards 路径各自验证 |
| 周常中文 | `oracle-weekly.mjs`、`src/data/oracle-weekly.zh.json` | 名称和说明分别降级，不能把代号假装中文 |
| browse 与其他推算 | `browse.mjs`、`browse-data.mjs`、`oracle.mjs` | 参考时间、有效窗口、缓存来源 |
| 图片目录和检索 | `local-images.mjs`、`gallery.mjs`、worker | content／wfcd／img 选择，官方精确 ID 后备 |
| 下载／图片索引 | `scripts/prepare-data.py`、`fetch-image-libraries.mjs`、`complete-image-libraries.py` | 新目录和索引要成套维护，不重复保存图 |
| 蓝图叠加与导出 | `image-composition.mjs`、`image-export.cjs`、`scripts/compose-blueprint.mjs`、`src/ui/images.js`、`gallery.js`、main | 同一 84% 成品区域；不改两张源图 |
| 文档阅读 | `documents.mjs`、`src/ui/documents.js`、main／worker／preload、`index.html` | Markdown 在白名单目录，纯文本 DOM 渲染 |
| 主题和布局 | `theme.js`、`workspace.css`、`style.css` | 全部入口、浮层、卡片和系统主题 |
| 打包和空间 | `package.json`、`scripts/package.mjs`、`retain-packages.mjs`、`storage-audit.py` | 只做 x64，外部图库、当前＋上一 ZIP |
| 命令行工具 | `工具/资料工具.mjs`、编号入口 | 参数数组传递，不通过 shell 拼接 |

## 建议的阅读顺序

先读对应深入章节，再读 core 实现，最后读 worker handler 和页面调用。修改规则时确认 UI 和 CLI 都能指定同一份合同；修改图片路径时同时处理获取脚本、目录选择、索引读取、工具和文档。
