## 必须保持的语义

1. 原始 JSON 只读。中文标题、字段解释、卡片和规范化产物不写回源文件。
2. 合并靠完整 ID、明确语言键、奖励表路径。键空间不同，名称相同不是关联证据。
3. 当前目录与快照上下文隔离；字段候选、转换、源文件哈希和指针要可追溯。
4. 未建模结构保留 reference／attributes，未知与缺失显式保留，不能为了统计漂亮而静默删除。
5. 蓝图底纹在下，精确成品图在上；P3 配方 resultId 或唯一明确 parent 是依据，不去掉名称后缀猜产品。
6. 技能、组件、强化 Mod、移植技能保持可跳转卡片；集团卡徽章要显眼，技能优先中文。
7. 赏金任务生成 seed、静态奖励表和实时奖励轮次确认是不同逻辑。缺概率不猜，候选表不静默挑一张。
8. 图像按源保存；官方按内容去重，WFCD 磁盘名按原始图名哈希。全图索引含嵌套和未引用素材。
9. 不直接执行抓取的 PHP／TS／Lua；只用受审阅的兼容算法或明确数据提取。
10. UI 文档是数据，阅读器不执行其中的 HTML 或脚本。
