## 项目处理的不是一份万能 JSON

原始文件用于核对来源；统一实体、配方和奖励用于消费；字典用于把完整键变成名称或说明；图片索引用于把 ID 关联到本地原图。它们分开保存，靠明确的完整键关联。

项目目前提供离线工作台和维护脚本，尚未把完整数据包部署到 App、uniCloud 或 ECS。后续 App 可以使用裁剪后的实体与索引，完整来源证据继续留在工作台。

## 当前约定

- 原始 JSON 保持只读；不把翻译、字段解释或卡片状态写回原件。
- 物品完整路径、语言键、奖励表路径属于不同键空间。不同名称相同不构成合并依据。
- 图片实体分来源存 `assets/content/wfcd/img`、`assets/content/official/img`、`assets/content/wiki/img`；不恢复旧独立工具目录。
- 蓝图底纹在下、精确成品图在上。关联不明时保留可用原图和缺失说明。
- 邮件暂不实现；文本标记 `<xxx>` 已接入中文语义展示，未知项保留原值。
- 2026-10-23 用户恢复测试；0.13.1 验证启动、合并展示和图库操作。排错不默认重新扫描大图库。
