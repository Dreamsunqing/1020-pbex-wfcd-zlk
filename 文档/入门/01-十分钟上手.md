# 十分钟上手

这是一个帮助团队理解星际战甲各来源 JSON、整理为统一离线数据的工作台。你无需先理解所有字段，也无需先下载整个图库。

## 先认识三个东西

- **原件**：`世界状态上游` 中按来源保存的 JSON、字典和规则。原件是核对依据，不在这里手改译名。
- **合并产物**：P3 生成的实体、配方、奖励、关系和来源证据。它是后续 App 取数的候选输入。
- **图库**：`assets/content/wfcd/img`、`assets/content/official/img`。通过完整 ID 和索引关联，不靠中文名字猜图。

## 开始使用

1. 打开 `dist` 中解压的应用，或在完整项目中运行 `npm start`。
2. “资料浏览”打开资料包目录。先按“类型=数据、语言=中文”缩小范围，再按来源和物品类别筛选。
3. 看一份熟悉的武器或战甲 JSON，分别切到“卡片”和“数据结构”：前者看记录，后者看这个文件有哪些字段。
4. “合并汇总”查看已有构建；没有时再点击“构建全量资料”。这是较大操作，只在需要生成或更新数据时执行。
5. 打开战甲详情，沿组件、技能、可移植徽章、集团卡和配方查看关系。原始值与翻译来源可以继续追溯。
6. “图片资源”搜索名称或完整 ID；看图、选择、复制或导出。需要时到配置确认共享图库路径。
7. “文档阅读”继续读本文的深入链接。

## 想跑脚本时

先读 [脚本地图](../深入/00-数据与图片流水线脚本地图.md)。根目录 `工具` 提供分别命名的入口；双击工具箱可选任务。单独运行某一个任务，不会自动串联下载、合并和全量校验。

```sh
node 工具/资料工具.mjs --help
node 工具/03-合并数据.mjs
```

第二条会实际构建并导出，不是预览命令。只想看要执行什么，可加 `--预览命令`。命令行入口需要安装项目依赖。

## 暂时不用关心的事

目前先理清离线数据，邮件、云部署留给后续；描述文本标记已有统一中文语义展示。Windows / Mac 应用共用同一份外部图库；跨电脑时除了程序也要带上原始资料和图库。
