# 目录与常见操作

## 哪些目录可以做什么

| 目录 | 用途 | 修改方式 |
| --- | --- | --- |
| `世界状态上游` | 固定的离线原始来源 | 通过来源维护流程更新；不要用页面翻译覆盖原件 |
| `assets/content/wfcd` | WFCD 图片与目录 | 用获取／处理图片工具维护，保留 img 与索引 |
| `assets/content/official` | 官方图片与 Manifest 索引 | 用官方图片工具维护 |
| `src/data` | 内置合并合同、修订、补译 | 开发人员通过代码审查修改 |
| `工具` | 清楚命名的可执行入口 | 使用这里运行；业务实现不另抄一套 |
| `文档/入门、深入、AI` | 当前说明 | 功能或路径变更时同步更新 |
| `文档/归档` | 当时的决策、验收和报告 | 保留历史适用版本，不能把历史统计当实时值 |
| `.workbench` | CLI 快照和合并存储 | 程序管理；不要只删对象却保留版本指针 |
| `输出` | 人工触发的导出 | 可以转交同事；确认用途后自行清理 |

桌面版默认把快照和用户规则存入系统应用用户目录，与 CLI 的 `.workbench` 分开；两者没有相同列表不一定是故障。完整说明见 [数据快照](../深入/01-数据获取与快照.md)。

## 常见需求

- **这条中文从哪里来**：在表格“中文来源”或详情的来源证据中看字典文件、完整键、指针和哈希。
- **修改合并结果**：先确认分类和字段规则，再用人工修订处理特例。不要直接改生成的 items JSON。
- **组件或技能打不开**：查看是否为显式待补引用，检查完整 ID、嵌套规则和源文件是否同一上下文。
- **奖励是哪类任务给的**：在赏金奖励卡片看中文上下文；候选表与已确认实时轮次应区别阅读。
- **没有图片**：核对配置是否选 `assets/content`、索引是否在对应来源目录；缺图可以保留文字，不需要重新下载所有图片。
- **找以前的方案**：文档阅读切换“归档”，或打开 [归档索引](../归档/README.md)。

“更新与版本”获取的新快照与本地资料目录是两个上下文。要比较历史或复现结果，应同时记录快照版本、规则版本和合并数据版本。
