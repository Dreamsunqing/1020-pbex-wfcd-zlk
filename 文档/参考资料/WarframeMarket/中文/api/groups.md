# 分组

分组用于管理订单和合约集合。

目前，接受 `groupId` 的接口支持两个虚拟分组：

| 分组 ID | 说明 |
| ----------- | --------------------------------------------------------------------- |
| `all` | 包含所有订单或合约，无论是否已分组。 |
| `ungrouped` | 仅包含尚未分配到任何分组的订单或合约。 |

用于创建、更新和删除自定义分组的管理接口将在之后公布。

目前已记录的分组相关接口见[更新订单组可见性](./orders.md#更新订单组可见性)。
