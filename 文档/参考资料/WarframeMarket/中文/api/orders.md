# 订单

交易市场订单接口。

## 获取最近订单

`GET /v2/orders/recent`

获取未被封禁用户最近的可见订单。

标记：支持平台／跨平台筛选，每分钟刷新

最多返回最近 `4h` 内创建的 `500` 个可见订单，按 `createdAt` 降序排列。仅包含当前在线用户。

### 请求

#### URL 参数

无。

### 响应

#### 正文

```ts
{
  apiVersion: "x.x.x",
  data: Order[],
  error: null,
}
```

`data` 是 [Order](../data-models.md#order) 模型数组。

## 按物品获取订单

`GET /v2/orders/item/{slug}`

获取某个物品的可见订单。

别名：`/v2/orders/itemId/{itemId}`

标记：支持平台／跨平台筛选

返回未被封禁用户的可见订单，用户的 `lastSeen` 须位于最近 `48h` 内，或未提供 `lastSeen`。响应中会刷新用户当前状态，但此接口不会移除离线用户。

### 请求

#### URL 参数

| 名称 | 类型 | 说明 |
| -------- | ------------------------------------------ | ------------------------------------------------------------ |
| `slug` | `string` | [Item](../data-models.md#item) 模型的 `slug` 字段。 |
| `itemId` | `string` | [Item](../data-models.md#item) 模型的 `id` 字段。 |

### 响应

#### 正文

```ts
{
  apiVersion: "x.x.x",
  data: Order[],
  error: null,
}
```

`data` 是 [Order](../data-models.md#order) 模型数组。

## 按物品获取最优订单

`GET /v2/orders/item/{slug}/top`

获取某个物品来自在线用户的最优买单和卖单。

别名：`/v2/orders/itemId/{itemId}/top`

标记：支持平台／跨平台筛选，自定义排序

响应最多包含 `5` 个 `sell` 订单和 `5` 个 `buy` 订单。

卖单从买家角度排序：优先排列 Endo（内融核心）挂单；Endo 挂单按每白金可获得更多 Endo 的顺序排列，其他挂单按每次交易所需白金更少的顺序排列。

买单从卖家角度排序：优先排列 Endo（内融核心）挂单；Endo 挂单按每白金对应更少 Endo 的顺序排列，其他挂单按每次交易可获得更多白金的顺序排列。

### 请求

#### URL 参数

| 名称 | 类型 | 说明 |
| -------- | ------------------------------------------ | ------------------------------------------------------------ |
| `slug` | `string` | [Item](../data-models.md#item) 模型的 `slug` 字段。 |
| `itemId` | `string` | [Item](../data-models.md#item) 模型的 `id` 字段。 |

#### 查询参数

| 名称 | 类型 | 说明 |
| -------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rank` | `int` | 精确物品等级。范围为 `0` 至物品最高等级。物品无等级或提供了 `rankLt` 时忽略。 |
| `rankLt` | `int` | 匹配低于此值的等级。范围为 `1` 至物品最高等级。优先于 `rank`。 |
| `charges` | `int` | 精确剩余使用次数。范围为 `0` 至物品最大使用次数。物品无使用次数或提供了 `chargesLt` 时忽略。 |
| `chargesLt` | `int` | 匹配低于此值的剩余使用次数。范围为 `1` 至物品最大使用次数。优先于 `charges`。 |
| `amberStars` | `int` | 精确琥珀星数。范围为 `0` 至物品最大琥珀星数。物品不支持琥珀星或提供了 `amberStarsLt` 时忽略。 |
| `amberStarsLt` | `int` | 匹配低于此值的琥珀星数。范围为 `1` 至物品最大琥珀星数。优先于 `amberStars`。 |
| `cyanStars` | `int` | 精确青蓝星数。范围为 `0` 至物品最大青蓝星数。物品不支持青蓝星或提供了 `cyanStarsLt` 时忽略。 |
| `cyanStarsLt` | `int` | 匹配低于此值的青蓝星数。范围为 `1` 至物品最大青蓝星数。优先于 `cyanStars`。 |
| `subtype` | `string` | 精确物品子类型。必须是该物品支持的子类型之一。物品没有子类型时忽略。 |

### 响应

#### 正文

```ts
{
  apiVersion: "x.x.x",
  data: {
    sell: Order[],
    buy: Order[],
  },
  error: null,
}
```

#### 数据字段

| 字段 | 类型 | 说明 |
| ------ | ------------------------------------------- | ------------------------------------------------------------------------------- |
| `sell` | `Order[]` | 最多 `5` 个在线用户卖单，从买家角度排序。 |
| `buy` | `Order[]` | 最多 `5` 个在线用户买单，从卖家角度排序。 |

## 创建订单

`POST /v2/order`

创建新订单。

标记：需要认证

**前置要求**

- 身份认证
- 账号已验证
- 用户未被封禁

### 请求

#### 正文

```json
{
  "itemId": "54aae292e7798909064f1575",
  "type": "sell",
  "platinum": 38,
  "quantity": 12,
  "visible": true,
  "perTrade": 6,
  "rank": 5,
  "charges": 3,
  "subtype": "blueprint",
  "amberStars": 3,
  "cyanStars": 3
}
```

#### 请求体字段

| 字段 | 类型 | 说明 |
| ------------ | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `itemId` | `string` | 必需。物品 ID；物品必须存在且可交易。 |
| `type` | `sell or buy` | 必需。订单类型。 |
| `platinum` | `int` | 必需。白金价格。最小 `1`，最大 `900000`。 |
| `quantity` | `int` | 必需。订单数量。最小 `1`，最大 `9999`。 |
| `visible` | `bool` | 订单是否可见。省略时默认为 `false`。 |
| `perTrade` | `int` | 可批量交易物品必需，其他物品禁止提供。最小 `1`，最大 `6`。必须能整除 `quantity`。 |
| `rank` | `int` | 物品支持等级时必需，否则禁止提供。最小 `0`，最大为物品最高等级。 |
| `charges` | `int` | 物品支持使用次数时必需，否则禁止提供。最小 `0`，最大为物品最大使用次数。 |
| `subtype` | `string` | 物品有子类型时必需，否则禁止提供。必须是该物品的子类型之一。 |
| `amberStars` | `int` | 物品支持琥珀星时必需，否则禁止提供。最小 `0`，最大为物品最大琥珀星数。 |
| `cyanStars` | `int` | 物品支持青蓝星时必需，否则禁止提供。最小 `0`，最大为物品最大青蓝星数。 |

### 响应

#### 正文

```ts
{
  apiVersion: "x.x.x",
  data: Order,
  error: null,
}
```

`data` 是精简 [Order](../data-models.md#order) 模型。

  "platinum": 10,

| ------------ | ------------------------------------------ | ----------------------------------------------------------------------------------------- |

| `rank` | `int` | 仅允许支持等级的物品提供。最小 `0`，最大为物品最高等级。 |
| `charges` | `int` | 仅允许支持使用次数的物品提供。最小 `0`，最大为物品最大使用次数。 |
| `subtype` | `string` | 仅允许有子类型的物品提供。必须是该物品的子类型之一。 |
| `amberStars` | `int` | 仅允许支持琥珀星的物品提供。最小 `0`，最大为物品最大琥珀星数。 |
| `cyanStars` | `int` | 仅允许支持青蓝星的物品提供。最小 `0`，最大为物品最大青蓝星数。 |

### 响应

#### 正文

```ts
{
  apiVersion: "x.x.x",
  data: Order,
  error: null,
}
```

## 关闭订单

`POST /v2/order/{id}/close`

关闭现有订单的部分或全部数量。

标记：需要认证

如果 `quantity` 大于订单剩余数量，服务会关闭剩余的全部数量。全部关闭会删除订单；部分关闭会更新剩余数量。

**前置要求**

- 身份认证
- 账号已验证
- 用户未被封禁
- 订单所有者，或角色为 `admin` 及以上的用户

### 请求

#### URL 参数

| 名称 | 类型 | 说明 |
| ---- | ------------------------------------------ | ------------------------------------------------------------ |
| `id` | `string` | [Order](../data-models.md#order) 模型的 `id` 字段。 |

#### 正文

```json
{
  "quantity": 12
}
```

#### 请求体字段

| 字段 | 类型 | 说明 |
| ---------- | --------------------------------------- | ----------------------------------------------------------------------------------- |
| `quantity` | `int` | 要关闭的单位数。最小 `1`，最大 `9999`。必须能被订单的 `perTrade` 整除。 |

### 响应

#### 正文

```ts
{
  apiVersion: "x.x.x",
  data: Transaction,
  error: null,
}
```

`data` 是精简 [Transaction](../data-models.md#transaction) 模型。

## 更新订单组可见性

`PATCH /v2/orders/group/{id}`

更新虚拟订单分组的可见性。

标记：需要认证

**前置要求**

- 身份认证
- 账号已验证

### 请求

#### URL 参数

| 名称 | 类型 | 说明 |
| ---- | ------------------------------------------ | --------------------------------------------------------- |
| `id` | `string` | 分组 ID。目前支持 `all`、`ungrouped`。 |

#### 正文

```json
{
  "visible": false,
  "type": "sell"
}
```

#### 请求体字段

| 字段 | 类型 | 说明 |
| --------- | ----------------------------------------------- | ----------------------------------------------------------------- |
| `visible` | `bool` | 要应用的可见状态。省略时默认为 `false`。 |
| `type` | `sell or buy` | 仅更新一种订单类型。省略时更新两种类型。 |

### 响应

#### 正文

```json
{
  "apiVersion": "x.x.x",
  "data": {
    "updated": 13
  },
  "error": null
}
```

#### 数据字段

| 字段 | 类型 | 说明 |
| --------- | --------------------------------------- | ------------------------- |
| `updated` | `int` | 已更新的订单数。 |
