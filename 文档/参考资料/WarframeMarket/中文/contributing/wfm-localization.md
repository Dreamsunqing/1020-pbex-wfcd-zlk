# wfm-localization

[GitHub 仓库](https://github.com/42bytes-team/wfm-localization)

`wfm-localization` 包含 Warframe.market 使用的界面翻译。改进菜单、按钮、表单、警告、筛选、设置和其他界面文字时，应编辑此仓库。

此仓库用于应用文字。物品名称、物品说明、紫卡属性、玄骸实体及其他游戏数据翻译通常应放入 [wfm-items](./wfm-items.md)。

## 适合贡献的内容

- 基于英语原文创建翻译文件，添加缺失语言。
- 补齐现有语言中的缺失键。
- 修复误译、不自然措辞、错字或术语不一致。
- 改进市场专用术语，使其符合相应语言玩家的实际表达。
- 翻译稀有度标签和生成文字模板等其他界面字符串。
- 英语字符串变化时，同步维护现有翻译。

相比大范围重写，小而集中的拉取请求更易审查。一次修改大量翻译时，请按语言或主题分组。

## 仓库结构

确切结构可能变化，但主要区域包括：

| 区域 | 用途 |
| ----------- | ---------------------------------------------------------------------------- |
| `locales/` | 主要界面翻译文件。 |
| `misc/` | 标签、模板和生成界面文字的附加翻译文件。 |
| `en.json` | 英语原文，也是新语言的最佳模板。 |
| `overwolf/` | 旧版／特殊集成文件。除非维护者要求，否则不要编辑。 |

## 翻译规则

只翻译值，不修改键。

```json
{
  "settings.language": "Language"
}
```

本例中翻译 `Language`，不要修改 `settings.language`。

花括号中的占位符通常必须保持不变：

```text
{itemName}
{count}
{platform}
```

字符串使用 ICU `select` 语法时，保留变量和选项名称，只翻译选项块中面向用户的文字。

```text
{platform, select, pc {} xbox {| Xbox } other {}}
```

本例中仅在目标语言需要时翻译 `Xbox` 等文字。不要重命名 `platform`、`pc`、`xbox` 或 `other`。

## 通过 Git 贡献

1. Fork 仓库。
2. 为相应语言或主题创建分支。
3. 编辑 `locales/` 或 `misc/` 中的相关文件。
4. 保持 JSON 有效。
5. 提交拉取请求，简要说明修改内容。

有用的拉取请求说明应包含：

- 语言代码。
- 是新增翻译还是更新。
- 你是否为母语／熟练使用者，或使用了其他来源。
- 可能需要维护者审查的术语。

## 不使用 Git 贡献

如果不熟悉 GitHub：

1. 在 GitHub 打开仓库。
2. 将仓库下载为 ZIP。
3. 在本地编辑或创建翻译文件。
4. 通过 [Warframe.market Discord](https://discord.gg/M7BHnPS) 将修改后的文件发送给维护者。

此方式比拉取请求慢，但仍欢迎翻译贡献。

## 审查要求

维护者主要检查：

- JSON 文件有效。
- 键未被意外重命名或删除。
- 占位符已保留。
- 贡献内容确实属于 `wfm-localization`，而非 `wfm-items`。
- 翻译不含玩笑、机器生成的无意义内容或无关重写。

我们可能无法亲自验证所有语言。母语或熟练使用者的社区审查很有帮助。

## 避免事项

- 不要翻译 JSON 键。
- 不要删除 `{itemName}` 等占位符。
- 除非被要求，否则不要编辑 `overwolf/` 文件。
- 不要将物品或游戏数据翻译移入此仓库。
- 不要将未经审查的机器翻译批次作为最终译文提交。
- 没有充分理由时，不要将许多无关语言混入一个大型拉取请求。
