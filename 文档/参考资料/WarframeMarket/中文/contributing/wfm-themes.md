# wfm-themes

[GitHub 仓库](https://github.com/42bytes-team/wfm-themes)

`wfm-themes` 包含 Warframe.market 自定义视觉主题。主题定义调色板和 SCSS 变量，让希望采用不同视觉风格的用户改变网站外观。

此仓库适合喜欢视觉设计、无障碍、对比度调整和 CSS／SCSS 的贡献者。

## 适合贡献的内容

- 创建完整的新主题。
- 改善现有主题的对比度或可读性。
- 修复缺失变量、错误颜色或编译问题。
- 调整颜色，使界面状态更容易区分。
- 让按钮、输入框、表格、卡片、导航和背景之间的主题更加一致。
- 改进主题构建或测试文档。

## 主题质量目标

好的主题不应只是随意更换调色板。

检查主题是否涵盖：

- 页面背景和表面颜色。
- 主要与次要文字的对比度。
- 链接及悬停状态。
- 按钮、输入框、下拉菜单及焦点状态。
- 表格、卡片、模态框和侧栏。
- 成功、警告、危险、在线、离线、买入和卖出指示。
- 对可读性要求较高的代码或数据密集页面。

主题应有鲜明视觉特征，同时适合市场操作流程。

## 要求

需要 Node.js 和 Sass 工具。

若仓库未在本地安装 Sass，可全局安装：

```bash
yarn global add sass
```

## 创建主题

1. Fork 仓库。
2. 在 `themes/` 下新建目录。
3. 以现有主题作为结构模板。
4. 在 `_main.scss` 中定义调色板和变量。
5. 编译主题。
6. 在真实 Warframe.market 页面测试。
7. 提交拉取请求并附截图。

## 编译

在 Linux 上，可能可以使用仓库构建脚本：

```bash
./build.sh
```

也可以使用 Sass 编译单个主题：

```bash
sass --no-source-map "./themes/{THEME_FOLDER}/_main.scss" compiled/{THEME_NAME}.css
```

迭代时添加 `--watch`：

```bash
sass --watch --no-source-map "./themes/{THEME_FOLDER}/_main.scss" compiled/{THEME_NAME}.css
```

## 测试

使用能够注入自定义 CSS 的浏览器扩展，在 Warframe.market 加载编译后的主题。

测试多个页面，至少检查：

- 主页或落地页。
- 物品页面。
- 订单列表。
- 表单和筛选。
- 用户个人资料页面。
- 相关的浅色／暗色敏感界面状态。

拉取请求附截图很有帮助。

## 无障碍

请注意对比度。

避免以下主题问题：

- 文字与背景混在一起。
- 链接难以与普通文字区分。
- 买入／卖出状态过于相似。
- 错误和成功颜色不清楚。
- 焦点状态消失。

不需要做到完美的无障碍审计，但主题应让真实市场浏览保持舒适。

## 拉取请求要求

好的拉取请求应包含：

- 主题名称。
- 简短的设计意图或灵感。
- 多个页面的截图。
- 已知薄弱之处的说明。
- 确认主题能够编译。

## 避免事项

- 不要提交只改一两种颜色的主题。
- 不要为了美观降低文字对比度。
- 不要破坏警告、错误、在线状态、买入或卖出等重要界面状态。
- 除非修复共享结构，否则不要在同一拉取请求中编辑无关主题。
- 不要只提交生成的 CSS，而不提交 SCSS 源码修改。
