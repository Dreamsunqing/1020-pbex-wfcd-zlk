# 历史归档

归档保留发生时的方案、计数、路径和验收结果，不代替当前规范。当前入口是 [文档总览](../README.md)。本轮只归档和改写入口，不重新执行归档中的校验／下载命令。

## 分区

- `过程记录/`：01～28 为原有连续记录，涵盖来源、筛选、Oracle、中文、P3、图片和双工具整合；29 为本轮目录与文档整理记录。
- `数据报告/`：原始文件清单、结构清单、P3 验收基线、图片比较等 JSON／TSV。报告日期和输入版本属于事实的一部分。
- `版本说明/`：0.11.0 时的 README 和使用说明。
- `图片工具/`：已删除独立图片工具的历史 README 与验收文档；许可证和必要原源码仍在 integrations。
