## 2. 官方 Public Export 的获取链路

1. 下载语言索引：`https://origin.warframe.com/PublicExport/index_<lang>.txt.lzma`。
2. 使用 LZMA Alone 格式解压，得到 `index_<lang>.txt`。
3. 按行读取索引中的版本化文件名，例如 `ExportResources_zh.json!00_qHCXLjOH5W47t2GBzcw2pQ`。
4. 拼接 `https://content.warframe.com/PublicExport/Manifest/` 与完整版本化文件名下载 JSON。
5. 校验 JSON、保存原始来源记录；本包阅读副本移除文件名的 `!…`，并以 2 空格缩进。

`!00_…` 是远端资源版本标识的一部分，下载 URL 必须保留；本地 `.json` 简名不能直接替代远端版本化 URL。索引中列的是采集时当前版本集合，本包并不是官方历代版本全集。

## 4. 脱离原项目，按快照重新获取

要求：Python 3.10+、Git，以及能够访问 Warframe CDN 和 GitHub 的网络。解压后从资料包根目录执行：

```bash
python3 工具/按快照重新获取.py \
  --snapshot 世界状态上游/snapshot-manifest.json \
  --output ./重新获取的上游
```

输出必须是不存在的新目录。脚本只使用 Python 标准库，不依赖原世界状态服务、npm、xz 或其他项目文件。它会：

- 优先复用随包历史压缩索引，按 LZMA Alone 解压并校验两份哈希；缺少随包索引时才访问线上索引，并要求与快照哈希完全一致。
- 下载固定版本 Manifest，先校验原始正文大小和 SHA-256，再去掉版本后缀、格式化为 `.json`。
- 完整克隆四个原仓库后，以 detached HEAD 检出快照固定提交。
- 检测到同目录 `wfcd-items-snapshot.json` 时，调用 `缓存WFCD无图片.py` 获取 WFCD 固定提交的全部非图片文件；没有 `.git` 和图片文件。
- 原样保留 `snapshot-manifest.json`，其中 `generatedAt`、`output`、`branch` 等仍是历史采集记录，不代表新输出目录和当前分支。

官方索引 URL 指向当前版本，可能已与历史快照不同，因此固定快照重取应保留随包的 `lzma/`。工具本次完成本地格式化复核、参数入口检查和本地模拟下载/Git 固定提交的集成演练，未实际联网重下全部资料。旧版 CDN 文件若被清理，脚本会报错；不会改用当前版本冒充旧快照。重新克隆的 Git 内部文件可能不同，不能使用本包的逐字节清单核对新克隆的 `.git`。

### 单个文件的手工获取示例

```bash
curl --fail --location \
  'https://origin.warframe.com/PublicExport/index_zh.txt.lzma' \
  --output index_zh.txt.lzma
python3 -c "import lzma,pathlib; p=pathlib.Path('index_zh.txt.lzma'); pathlib.Path('index_zh.txt').write_bytes(lzma.decompress(p.read_bytes(), format=lzma.FORMAT_ALONE))"
curl --fail --location \
  'https://content.warframe.com/PublicExport/Manifest/ExportResources_zh.json!00_qHCXLjOH5W47t2GBzcw2pQ' \
  --output ExportResources_zh.raw.json
```

上例第二个 URL 固定到本快照资源版本，原始 SHA-256 为 `e30867c7d8d6a696f46715d4ef51ebcb94239a5774dd0a838a50e887946d828a`。获取新版本时应重新下载索引并读取其中版本化名称，不能沿用示例哈希。

获取最新官方资料：重新下载 15 个语言索引，逐条下载其当前 Manifest，保存到新的目录，并生成新的来源清单。获取最新社区资料：在新目录 `git clone` 各仓库，记录实际 HEAD；或在已有克隆 `git fetch` 后自行核对目标提交，再检出目标版本。仅执行 fetch 不会更新工作树。
