# 0.1.1 多维筛选与浏览布局

日期：2026-10-20（Asia/Shanghai）。基于 0.1.0 第一版，跨来源合并（P3）和邮件仍未实现。

## 变更

- 来源、类型、语言、数据类别均采用多选 picker。同组取并集，不同组取交集，并叠加 JSON 开关和路径搜索。
- picker 支持选项搜索、清空本项、匹配数；匹配数不受本项已选值限制。已选条件显示可移除标签，支持一键清空。
- 文件目录显示四维徽章；复合类别支持多个值，长标签以悬停提示显示全文。
- 从来源及相对路径推断元数据，本地和历史快照共用规则，原始文件和历史清单不改写。
- 语言区分 15 种已知语言、语言无关、语言未标明。综合字典归为综合类别；未知文件可搜索。
- 表格键 / 类型 / 内容列由 24% / 12% / 64% 调整为 16% / 9% / 75%；结构视图同步缩窄键和类型。

## 验证记录

- 桌面烟雾测试：570 个文本文件，读取 3549 条资源，3 个活化组合、24 条仲裁及渲染隔离通过。

- 验证每个目录条目显示四维徽章、空结果提示、picker 内搜索、单标签移除；测量内容列占比 75%。
- 1080 × 720 视口中无水平溢出，picker 完整位于视口内。

截图与自动化结果位于 `artifacts/facets/`；应用更新包位于 `dist/SourceWorkbench-0.1.1-*.zip`。
