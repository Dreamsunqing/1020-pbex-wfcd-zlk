# Oracle 五组推理 · 0.3.0

桌面入口：“推算实验室 → 五组推理 · Oracle”。本次新增赏金轮次、地区赏金与入侵任务变化，连同已有的活化战甲和仲裁排期，共五组。CLI 与桌面共用计算核心。

## 数据与行为

- 赏金轮次：按 Hex seed、阵营奇偶、挑战去重和 1999 同伴排除规则，复算扎里曼、英择谛实验室与 1999 的 17 档任务；奖励轮次来自有效世界状态。
- 地区赏金：按 Cetus seed 和所选三份地区清单中的顺序，复算平原、山谷、火卫二 15 个地区；保留完整任务路径。
- 入侵变化：按双方 seed 和 UTC 15 分钟轮次复算任务，覆盖飞船、感染者和 Boss 分支；UTC 零点重置随机数推进。后续最多 8 轮假定当前入侵继续存在，不预测新增或结束。
- 活化战甲保持原有历史输入与条件推算；仲裁继续查询缓存排期，不生成表外结果。
- 规则来自所选目录或快照；只解析所需数据，不执行上游 Pluto/Lua。三份规则源码按审阅哈希检查，变化时拒绝计算。结果包含原始键、中文标签、规则／输入哈希、快照 ID 和世界状态来源。
- 官方世界状态刷新与本地 JSON 导入使用独立缓存 `runtime/oracle-world-state.json`。仅保留必要字段；导入以参考时间作为采集时间用于回放。赏金窗口过期、入侵超出采集的 15 分钟窗口会报错；刷新或导入失败保留原缓存。
- 两项赏金支持手填 64 位十进制 seed 离线复算，此时不声称为当前轮次，不猜奖励轮次。入侵始终需要世界状态。切换资料清除旧结果，失败查询清除对应旧展示和可复制结果。

## 验证记录

`npm run check` 检查 32 个代码文件；`npm test` 共 35 项，新增 9 项覆盖 Oracle 算法、数据、缓存和真实桌面 worker。测试包括七组独立 Python seed 向量、部分同伴分支、阵营／挑战去重、64 位边界、UTC 零点、15 分钟边界、过期数据、损坏规则和导入失败保留，以及本地目录和两份快照切换。独立参考生成器为 `scripts/oracle-reference.py`。

真实 Oracle 响应与官方世界状态取样于 2026-10-19 18:51:52 UTC，固定在 `test/fixtures/oracle-service.json`。seed 24091 的全部节点、挑战、同伴、地区任务、奖励轮次，以及当时入侵双方当前／下一轮任务均与服务响应一致；这不是游戏实测。

`scripts/check-ui.mjs` 验证五个入口、17 档挑战、15 地区、6 条入侵阵营记录、2／8 轮展示、中文标签、JSON 复制数据、坏 seed／过期清除、任意路径 IPC 拒绝、目录刷新清空，1080×720 无横向溢出。设置 `WORKBENCH_NETWORK_TEST=1` 的真实按钮请求通过，能显示官方来源并恢复按钮；browse.wf 四组功能同时回归通过。多维筛选单独回归保留 11 个组合结果、3 份中文字典和 75% 内容列宽。

界面记录位于本地忽略目录 `artifacts/oracle/`：`ui-overview.png`、`ui-locations.png`、`ui-invasions.png`、`ui-narrow.png` 和 `ui-result.json`。
