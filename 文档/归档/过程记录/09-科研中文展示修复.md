# 科研中文展示修复 · 0.4.1

0.4.0 的英文来自两种情况：已翻译条目旁一直显示的原始标识，以及上游中文缺项后直接回退英文键。此次分别调整展示和中文回退逻辑。

## 中文来源

先按字段读取所选来源的中文，再查应用自带补充表，仍缺失则标记待补中文。以后上游收录中文时，无需改代码即可优先使用上游。空白、英文和原始路径不视为已完成中文翻译。

本包 Oracle 中文字典缺少下列更新 44 新增项。名称为本项目补译，效果由 [官方更新 44 的 Additional Personal Modifiers](https://www.warframe.com/en/patch-notes/pc/44-0-0) 核对：

| 原始键 | 补充中文名 | 效果说明 |
| --- | --- | --- |
| `NoPets` | 禁止携带同伴 | 禁用同伴，Khora 的 Venari 不受影响 |
| `RangeDebuff` | 范围缩减 | 技能范围减少 50% |
| `AnemicShields` | 贫弱护盾 | 最大护盾和过载护盾不超过 500 点 |

补充表为 `src/data/oracle-weekly.zh.json`，版本 `weekly-zh-1`，含依据、核对日期和条目，随应用版本发布。上游原始文件不改写。JSON 结果包含该表哈希、名称／说明各自的翻译来源和待补键，能区分上游文本、本项目补译与缺项；静态快照 ID 和应用补充表分别追踪。

## 展示

主界面保留中文名称和说明。任务类型、变体、风险、个人限制的英文键、名称转换和翻译来源默认折叠，点击“原始标识与翻译来源”展开。补译有“补充译文”徽章。六人组标题显示“六人组 · 时光科研”。

未知新项显示“中文名称待补充／中文说明待补充”，结果列出待补键；原始值保存在展开详情和复制 JSON 中，避免把未翻译状态误当作中文完成。

## 验证与交付

`npm run check` 检查 34 个代码文件，`npm test` 共 41 项通过。新增覆盖三个新限制、补译出处、补充表哈希、上游优先和未知项标记；原有 Oracle 服务兼容字段保持一致。

桌面检查验证 6 任务、12 风险和 8 限制；这组数据无待补中文键。默认视图不显示技术英文键，展开后仍可读原始标识，4 个使用补译的条目显示徽章（实验室与六人组各有一项 NoPets）。1080 宽度下布局正常。
