# JSON 卡片与中文标题 · 0.5.0

JSON 预览增加“卡片”，与表格、结构、原文并列。卡片展示中文标题、原始名称、来源详情和最多 8 个非图片字段，沿用每页 80 条、当前层级搜索与 JSON Pointer 跳转。图片相关字段在卡片中隐藏，不创建图片或其他媒体元素、不下载图片；原文、表格和导出保留原有图片路径文本。

标题优先采用 name、title、displayName、label 等字段中的已有中文。缺少中文时，以名称、uniqueName、type、记录键或字符串值中的完整 /Lotus/ 路径查中文词典：Plus / Oracle 的“路径→字符串”和 WFCD i18n 的“物品路径→name”。同来源优先，其后依次为 Plus、WFCD、Oracle 和其他中文字典。不按英文名或路径尾段猜测，不使用 description、icon 等字段充当标题；未命中保留原名并标记“未匹配中文”。只读取当前目录／所选快照内的词典，不联网翻译。

表格新增“中文来源”，内容列上方显示解析的中文标题；键、类型、内容、来源占 13%、7%、65%、15%。展开来源可查看文件相对资料根目录的完整路径、JSON Pointer 与字典 SHA-256。记录自身中文标为“原文”。显示信息独立于原始对象，不注入复制和导出，也不写入源文件或快照对象。

字典按内容哈希缓存解析索引，每次预览重新核对内容；本地修改立即生效，新增文件需刷新目录。历史快照同时固定数据和词典，切换目录或快照后使用对应版本。字典缺失或损坏只产生提示并降级，不阻塞原始数据预览。
