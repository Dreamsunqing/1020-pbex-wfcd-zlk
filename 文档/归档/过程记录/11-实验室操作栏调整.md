# 实验室操作栏与模块条件 · 0.5.1

主导航调整为“资料浏览 → 推算实验室 → 更新与版本 → 配置”。

实验室的 browse.wf、Oracle 两个页签，顶部均只保留一个参考时间输入和一个深绿色“刷新并查询”按钮。时间默认为当前时间；从未手动编辑时，刷新后随当前时间更新；手动编辑后保留所选时间。按钮刷新对应世界状态缓存后查询本页全部模块，处理中禁用以避免重复点击，结束后恢复。刷新失败仍按已有缓存执行本地查询，并明确显示刷新失败；没有有效输入的模块继续显示缺失／过期提示。

各类条件放回对应模块，修改后只重算该模块，不额外联网：

| 模块 | 条件及默认值 |
| --- | --- |
| Teshin 周商品 | 查询周数，默认 4 周 |
| 普通／钢铁回廊 | 独立查询周数，默认 4 周 |
| 每日突袭 | 查询天数，默认 7 天 |
| 01 赏金轮次 | Hex seed，留空使用有效世界状态 |
| 02 地区赏金 | 独立 Cetus seed，留空使用有效世界状态 |
| 03 入侵变化 | 当前＋下一轮，可改为 4／8 轮 |
| 04 实验室／Hex 周常 | 世界状态 JSON 导入入口，按顶部时间记录采集时间 |
| 05 活化战甲 | 游戏名、目标周、历史战甲；示例名 Tenno、本周、无历史 |
| 06 仲裁排期 | 未来小时数，默认 24 小时 |

Oracle 六个模块共用顶部参考时间，移除活化和仲裁的独立时间框及查询按钮。导入世界状态后重新查询六个模块。模块实际排列、标题编号和快捷入口保持一致。活化示例名明确标注可替换，缺少历史仍返回条件推算。

查询响应按模块记录请求代次，同时校验所选资料代次；更新某个模块的条件不会取消或覆盖其他模块的查询结果，切换资料后不显示旧版本的延迟结果。复制 JSON、原始数据只读及既有计算规则继续沿用。
