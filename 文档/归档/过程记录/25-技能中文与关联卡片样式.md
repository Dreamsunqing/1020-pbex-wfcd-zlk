# 0.10.1 技能中文与关联卡片样式

日期：2026-10-22。基于 0.10.0，调整技能展示和集团卡入口；合并数据格式与数据工作包沿用 0.10.0。

## 本次界面

- 技能与组件使用同一套跳转卡片，显示中文名称、技能序号／组件数量、内部 ID 和明确的“查看技能详情／查看组件详情”按钮。点击卡片空白区域也可跳转，键盘 Enter／空格可进入详情。
- 标准集合字段中的技能、组件等引用同样显示为卡片，避免只看到 `itemId` 的对象树；详细候选和原始数据仍可展开查看。
- 集团卡／强化卡入口使用深绿实心按钮，直接显示对应 Mod 中文名及跳转箭头。多张卡各有独立按钮，无需悬停才能辨认。
- 列表卡片仍保持精简徽章；在技能、武器详情和关联卡片内展示完整 Mod 名称。Mod 关联卡使用淡绿底和明显边框，保留反向跳转。
- 关联来源折叠到“关联来源”中，避免与主要跳转入口混淆。移植标记保持独立的紫色样式。

## 中文标题补充

原资料预览之前仅识别通用 `name` 等字段，遗漏官方技能的 `abilityName`／`abilityUniqueName`。本版将这两个字段纳入标题解析，并建立只读技能中文索引：

1. 从官方中文 `ExportWarframes_zh.json` 的 `ExportAbilities` 与战甲内嵌 `abilities` 读取中文名称。
2. 从 Plus `ExportWarframes.json`、`ExportAbilities.json` 获取技能完整 ID 和语言键，再查现有中文字典。
3. 以完整技能 ID 对应原预览条目，显示中文并保留来源文件、真实 JSON Pointer 和哈希；不会按英文相似度猜测。

有中文来源时优先显示中文；确实没有中文资料时保留原名／ID。不会自造技能名称，也不会修改原始 JSON。索引按源文件哈希缓存，字典与技能元数据更新后自动刷新，快照与本地来源各自隔离。

例如 Gauss 技能显示“马赫冲驰、动能镀层、热能抽离、赤限”；“集团卡 · 马赫崩毁 ↗”“集团卡 · 热能传递 ↗”分别跳到对应 Mod。

## 兼容与交付

已有 0.10.0 全量构建可直接使用新样式，无需重新构建、导出或下载同内容的数据工作包。较早版本仍需按原提示构建一次全量资料。

只提供 Mac x64、Windows x64。两端包均校验后保留 0.10.1 当前版与 0.10.0 上一版 ZIP，不生成 Mac arm64。数据 ZIP 保留上一轮实际交付的 0.10.0 与 0.9.0。

## 验证

`test/preview-titles.test.mjs` 增加官方技能字段和真实 Gauss 技能的中文解析验证，覆盖无匹配时降级、来源回查及原始文件不变。

`scripts/check-nested-ui.mjs` 增加四个中文技能名称、统一卡片外观、中文 Mod 名入口、键盘进入技能及点击卡片进入组件的验证；继续验证徽章目标、返回、Prime 移植标记、来源行号及 1080 宽窗口。

核心数据的匹配规则、移植依据和未匹配限制见 [0.10.0 嵌套合并与关系导航](24-嵌套合并与关系导航.md)。

当前 WFCD 快照的 501 份战甲技能记录均提供 `uniqueName`，同样按完整技能 ID 显示中文，不需要按英文名称或数组序号猜测。
