# 0.10.2 技能图片、奖励卡片与官方图库比较

> 2026-10-22 后续复核：本篇图库数字统计的是当时被裁剪的本地顶层目录。WFCD 已恢复完整 12,543 个文件，按内容去重为 12,426 张；官方 12,501 张，相差 75 张。完整结果、实体保存位置和校验说明见 [完整图库恢复与复核](27-WFCD完整图库恢复与官方图库复核.md)。下文保留当时的统计口径和功能验收记录。

## 本次交付

- 技能、组件等关联卡片、技能详情、统一资料列表及原 JSON 卡片共用本地图片入口。优先所选 WFCD 图库，缺失技能图使用本次内置的小型 WFCD 补充库。
- 赏金奖励表用多列卡片，默认不创建奖励明细 DOM。展开该表后占用整行，奖励多卡排列；原始概率、包数换算、稀有度及来源仍可查看。图片有则显示，不因缺图阻断浏览。
- Oracle 01 赏金轮次也采用任务卡片，多档并排，展开某档奖励后占整行。01／02 的奖励明细采用多列小卡，继续默认折叠；01 增加地区／档位与当前任务挑战的中文关联说明。
- 读取已有合并产物计算显示信息，不改变 canonical JSON、datasetVersion 和原始上游。不需要重新构建 0.10.0 数据包。
- 获取官方 Public Export 图片，单独缓存并与本机 WFCD 图库按同一完整 ID 比较；不将大图库复制进应用或上游 JSON 目录。

## 中文奖励出处的生成

入口 `src/core/merge/reward-context.mjs`，按当前构建中保留的参考 JSON 计算并缓存：

| 输入 | 引用字段 | 获得内容 |
| --- | --- | --- |
| Oracle 六个 `*JobManifest.json` | `JobDifficultyTiers[n].rewardManifests[]`、`ChallengeMissionDifficultyTiers[n].rewards` 等完整奖励 ID | 地区、清单第 n+1 档；存在时显示敌人等级、任务阶段总数、额外／无尽标记 |
| Plus `ExportRegions.json` | `rewardManifests[]` 等直接奖励 ID | 星球、节点中文名、任务类型 |
| Plus `ExportRelics.json` | `rewardManifest` | 合并中文检索索引中的遗物名与原描述 |
| Plus `ExportKeys.json`／`ExportBounties.json` | 记录中对奖励表的完整引用 | 剧情／钥匙／赏金任务名称及描述 |
| Plus／Oracle 中文字典 | `name`／`systemName`／`missionName`／`description` 的语言键 | 中文文本 |
| 明确列举的奖励路径目录 | 如 `SurvivalMissionRewards`、`EventMissionRewards` | 人工中文分类，明确标记“按路径目录”，不冒充直接任务引用 |

说明优先直接引用，保留所有用途和源文件／JSON Pointer／哈希；若同表被多处使用，展开“任务说明与奖励来源”查看所有引用。缺少依据时保留“来源待补充”。稀有度不转换成百分比，池号不转换成任务阶段，不推断活动当前开放。显示信息可中文搜索。

当前 1,102 张奖励表：978 张有直接引用，110 张按目录分类，14 张来源待补充。规则和原始字段可继续逐类复核，当前展示并非已经确认的游戏实时奖励状态。

## 官方图片下载与复跑

```bash
# 同时补齐 WFCD 技能图和官方图库；仅开发时按需运行
node scripts/fetch-image-libraries.mjs
# 已有技能图时只下载／校验官方缓存，并重新生成比较报告
node scripts/fetch-image-libraries.mjs --official-only
# 只维护随包的小型技能图库
node scripts/fetch-image-libraries.mjs --skills-only
```

本机对比图库默认为同级 `给写攻略人员准备的图片提取工具/assets/content`，其他位置可用 `WORKBENCH_WFCD_IMAGES` 环境变量指定。命令遵循 HTTP(S)_PROXY／NO_PROXY。

以 `official-public-export/manifests/en/ExportManifest.json` 的 `Manifest[].uniqueName → textureLocation` 为依据。其他语言 Manifest 相同，不重复下载。图片地址为：

```text
https://content.warframe.com/PublicExport/<完整 textureLocation，去掉开头斜杠>
```

保留文件名后的 `!版本哈希`；图片地址不增加 `/Manifest/`。本地资产以内容 SHA-256 存一次，ID／URL 映射在 `index.json`。有超时、最多三次重试、8 MiB 响应上限、PNG/JPEG 签名验证和断点检查；HTML 错误页不保存为图片。运行中保存 checkpoint，完成后发布当前 index。资源文件位于 `.workbench/official-images/assets/`，不混入原始资料和 WFCD 图库。清单变更保留当前与上一份 index，两者共同引用的资产只存一份，回收不再引用的旧资产。

比较程序只把本机 `catalog` 声明为 `original` 且文件真实存在的 WFCD 图片计入；参考配图不计入原图。分别列出原图库，以及本次技能补充库。**同一图片可供多个物品使用，物品 ID 数与图片文件数不能混比。**

## 官方与本机 WFCD 的实测结论

基于当前保存的官方 Manifest 与本机攻略图片工具 catalog。这里比较的是**这份本机 WFCD 图库**，不能据此声称 WFCD 上游永远没有某张图。

| 指标 | 官方 Public Export | 本机 WFCD 原图库 |
| --- | ---: | ---: |
| 声明／已有图片关联的完整物品 ID | 20,144 | 19,234 |
| 本次有效图片关联的 ID | 20,143（1 个 404） | 19,234 |
| 资源地址／目录文件 | 12,624 个地址，12,623 成功 | 12,233 个文件 |
| 按位图内容 SHA-256 去重 | 12,501 张 | 12,117 张 |
| 去重位图总大小 | 922,974,823 字节，约 880.22 MiB | 620,159,435 字节，约 591.43 MiB |

**物品覆盖上官方更广，去重图片数量多 384 张。**完整 ID 有 19,230 个共有；官方清单另列 914 个 ID，本机另有 4 个 ID 不在本份官方清单中。官方新增声明中 913 个实际取图成功，另一个是头像 404。

914 个额外 ID 的构成：

| 部分 | ID 数 | 说明 |
| --- | ---: | --- |
| 战甲／Archwing／殁世机甲／Helminth 等技能 | 308 | 本次已用 WFCD 补充库覆盖这 308 个 ID、305 张图 |
| 组件蓝图 | 480 | 按完整组件蓝图 ID 多出关联；大量蓝图共用头部神经光元、机体、系统等通用部件图 |
| 其他 | 126 | 含头盔 29、宠物外观礼包 25、加成 19、装备资源礼包 13，以及装备／晶体／物品栏等；含一个失效头像 |

这些 914 个 ID 总共只涉及 444 个版本化纹理地址；其中 369 个地址未被双方共有 ID 使用。还有 534 个 ID 的纹理原文件名能在本机图库的原图名中精确找到，往往是**关联缺口或共用图**，不能解释成 914 张全新的图案，也不能单凭同名断言版本像素相同。

计入本次 WFCD 技能补充库后：WFCD 共可按 ID 覆盖 19,542 项，双方共有 19,538 项；官方清单还多 606 项（605 项取图成功，1 项 404），本机仍有 4 项独有。另有 1 个原图库缺口能通过严格的 StoreItems 前缀转换关联已有条目，统计保留原 ID，没有偷偷合并。

本机独有的 4 项：

- 冰川实验室场景 — `/Lotus/Types/Items/PhotoBooth/Zariman/PhotoboothTileZarMelicaLabTreasureRoom`
- 肤色 B-17 [经典] — `/Lotus/Upgrades/Skins/Operator/Heads/ExtraAdultAlbedoC`
- 肤色 B-17 [经典] — `/Lotus/Upgrades/Skins/Operator/Heads/ExtraAlbedoC`
- Tennotober 2026 Prex — `/Lotus/Types/Items/ShipDecos/TarotCard2026Tennotober`

官方地址中成功下载 PNG 11,265 个、JPEG 1,358 个（这里按地址计，尚未按内容去重）。两库主体都是 512×512；官方去重图中有 10,811 张 512×512、1,506 张 256×256，本机目录有 10,646 张 512×512、1,495 张 256×256。官方原图总空间更大，并不意味着所有图片分辨率更高。双方共有 ID 的图文件字节哈希均不同；格式、编码、压缩及版本可能造成差别，本轮没有把“不同字节”当成“不同图案”。

唯一失败项：

- `/Lotus/Interface/Icons/Player/ContentCreators/DeathMa666ot.png!00_w3OCAqKWH5ngubC29LD+Cw`，官方 CDN 返回 HTTP 404；复跑后仍相同，保留失败原因，不用 HTML 错误页冒充图片。

官方图按完整 ID 可为后续缺图提供候选。当前应用继续优先本机 WFCD 图及随包技能图，蓝图使用现有底纹加成品图的合成规则。官方大型缓存单独保留一份，不复制进应用 ZIP。

机器可读摘要：[官方与 WFCD 图片覆盖比较](../数据报告/官方与WFCD图片覆盖比较-0.10.2.json)。完整逐 ID 差异、失败 URL 与分类在本机 `artifacts/image-comparison/report.json`；完整下载清单及 SHA-256 在 `.workbench/official-images/index.json`。
