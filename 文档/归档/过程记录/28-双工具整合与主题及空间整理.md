## 用户操作

图片入口提供来源（WFCD／DE 官方／全部）、类别、图片状态筛选，以及中文、英文、原图名和完整 ID 搜索。支持 Unicode 全角输入和多个关键词；精确名称及名称前缀优先，防止搜索武器时材料排到武器前面。材料仍可通过所属装备名称查询。

每页 72 张统一卡片，底色可选透明棋盘、浅色、深色；大小可选紧凑、标准、大图。卡片只保留图片、名称、英文名、来源与类别，长描述放到详情中。技能图使用适合白色图标的深绿底。

详情包括尺寸、格式、字节大小、中文和英文标题、描述、原图名、完整 ID、纹理路径及关联物品；可缩放、复制图片、复制名称、保存原图，继续查看关联图片，或进入已有合并实体。

选择跨分类和分页保留；可选择本页、只看已选、清空选择，按中文／英文／双语文件名导出所选原图。同名自动编号，原图字节保留。批量导出有进度、停止操作和失败汇总；停止后已成功的图片保留。导出过程中关闭窗口会提示先停止，不中途强制终止写入。

右上角支持浅色、暗色、跟随系统。跟随系统会响应系统主题变化；选择和图库外观偏好均在重启后保留。⌘ / Ctrl K 聚焦当前页面搜索，Esc 关闭图片详情。主题覆盖资料浏览、合并汇总、规则、推算、更新、配置、图库和弹窗，原生文件对话框也使用对应主题。

迁移使用目录移动，没有再复制一套图库。原 `src/data/ability-images` 的 305 张图逐文件确认与完整图库 SHA-256 相同后移除，技能统一通过完整清单定位。原始 JSON、合并资料、图片资源保持各自用途，文件名不再依赖旧工具路径。

资料卡片先取 WFCD 的精确 ID／原图名关联；普通记录缺图时，再用完整 ID 查本地官方索引。不会按英文名称模糊猜图，也不会下载记录里的远程图片 URL。蓝图继续沿用“蓝图底纹 + 精确成品图”的组合规则。敌人参考图在图库明确标记，不冒充普通资料卡的原图。

图库本身的比较不变：WFCD 按内容去重 12,426 张，官方 12,501 张，相差 75 张；官方多出的 606 个 ID 不能解释成 606 张新图。完整统计见 [图库复核](27-WFCD完整图库恢复与官方图库复核.md)，当前实体位置以本篇为准。

## 删除与空间核对

旧目录删除前做了以下核对：

1. 全部 12,543 个 WFCD 文件与固定快照 Git blob SHA-1、长度及 SHA-256 一致；全部 12,501 个官方文件验证 SHA-256、长度和图片签名。
2. 原源压缩包内的 153 个非图片文件与现有 WFCD 源码快照逐字节一致；被文本快照排除的内嵌 SVG 数据另存 `assets/provenance/wfcd-logo.json`。
3. 原工具源代码、许可证、历史说明和测试记录迁为小型维护参考；敌人审核源资料与必要维护脚本保留。
4. 合并后的真实 Electron 窗口已验证检索、图片读取、系统剪贴板和导出，再删除旧目录。

移除旧项目中 4,638,999,573 字节（约 4.64 GB）的文件，主要是重复的预览程序、打包缓存、旧独立发布包、依赖和约 604 MiB 的源压缩包。这个数是删除文件的逻辑字节数，不等于精确实测的磁盘可用空间变化。

对 `tools` 下的数据进行内容哈希审计后，395 组、423 个重复文件的 560,122,458 字节内容改为 APFS 写时复制共享。路径仍各自独立，修改一份不改变另一份；没有使用把可变文件绑在一起的硬链接。审计覆盖大于等于 4 KiB 的普通图片、JSON、文本和源码文件，排除 Git 历史、运行依赖、应用包、符号链接和运行时二进制。小文件、不同版本、不同编码或不同像素的图片不凭名称删除。

`du` 通常按文件逻辑分配计数，会把共享区块重复列出，不能据此判断 APFS 克隆没有生效。共享字节数也不是实际释放空间的测量值。Git 历史和开发依赖属于运行／开发用途，保留；其他 `tools` 项目的独有内容不删。

合并仓库构建也改为：若新旧构建文件哈希相同，使用系统支持的写时复制，而不是再次写一份相同字节。每个上下文仍仅保留当前和上一份构建。应用包保留 0.11.0 和 0.10.2 的 x64 ZIP，淘汰更早应用 ZIP；数据 ZIP 继续使用原当前和上一份。

## 核心实现

| 文件 | 职责 |
| --- | --- |
| `src/core/gallery.mjs` | 合并两种图片索引、中文与英文标题、分页筛选、详情关系及受目录约束的读取 |
| `src/core/local-images.mjs` | 完整图名／ID 清单、技能图标、蓝图组合与原配图规则 |
| `src/core/image-export.cjs` | 来自原 MIT 图片工具的安全命名、原图复制及重名编号 |
| `src/desktop/main.mjs` | 受限本地图片协议、原生剪贴板、保存／批量导出、进度和主题 |
| `src/desktop/worker.mjs` | 图库查询、精确官方补图与资料操作，避免解析阻塞界面 |
| `src/ui/gallery.js` | 统一卡片、选择、筛选、详情、缩放和导出体验 |
| `src/ui/theme.js`、`workspace.css` | 首屏主题、系统变化、明暗配色、布局及可访问性 |
| `scripts/complete-image-libraries.py` | 无需保留源压缩包即可按固定 Git 清单校验现有完整图库，复核官方库 |
| `scripts/prepare-data.py` | 维护者更新完整 WFCD 图库，保留独立官方目录 |
| `scripts/storage-audit.py` | 内容审计；macOS 下可按精确哈希转换为独立的 APFS 克隆 |

图片协议只接受现有索引键，后台校验 realpath、文件类型、图片签名及 8 MiB 上限；普通资料卡有更小的单图／批次限制。前端不获得任意磁盘路径，说明使用纯文本渲染。原始 JSON 不变。

## 打包与迁到其他电脑

Mac x64 和 Windows x64 应用仍位于 `dist/`。共享图库不复制进每份应用 ZIP；已有完整源码目录下的开发版与发布版自动向上寻找同一份 `assets/content`。跨电脑移动时，带上该目录及 `世界状态上游`，必要时在配置中手动选择。只复制程序 ZIP，不会自带约 1.5 GB 图库。

本轮没有新增独立图片工具的发布包，没有 Mac arm64 包。历史独立工具二进制不再作为另一个产品保留。
