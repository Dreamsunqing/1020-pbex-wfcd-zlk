# 0.12.0 图库目录、文档工具与阅读入口

日期：2026-10-22。用户要求停止测试，调整图库结构，整理面向新人／深入开发／AI 的文档、可运行脚本、历史归档，并增加程序内文档阅读。当前规范见 [文档总览](../../README.md)。

本轮使用目录移动将 WFCD 放入 `assets/content/wfcd/img`，官方放入 `assets/content/official/img`。索引随所属来源保存；官方兼容链接指向新位置。读取、下载和维护实现同步改路径，不保留第二套实体。

新增 `工具/资料工具.mjs` 和编号 01～09 入口，覆盖获取数据、结构处理、合并数据、两种图片获取、完整图片整理、蓝图合成、启动和打包。原先三份固定原始包 Python 工具保留，校验清单路径适配到归档。

蓝图按已有配方 resultId 或目录唯一 parent 叠加，底纹全尺寸，成品 84% 居中；不猜成品、不覆盖源图。图库预览和复制／保存／导出增加同样规则，可用脚本另存透明 PNG。关联不足时保留单图，CLI 拒绝生成误导性合成。

文档分总览、入门、深入、AI、归档。根 README 与使用说明缩为当前入口；旧 01～28、JSON／TSV 报告、0.11.0 说明和图片工具旧说明分别移动保存。阅读器支持分组全文搜索、章节跳转、文档链接、返回、Markdown／代码复制、字号及最后阅读记录；随应用保存 Markdown，完整项目优先读外部当前文档。

本轮不运行自动测试、完整图库扫描或下载。构建 ZIP 不等于新功能通过验收，历史测试记录不归到当前版本。新布局与阅读器的运行问题留待用户实际使用反馈后处理。
