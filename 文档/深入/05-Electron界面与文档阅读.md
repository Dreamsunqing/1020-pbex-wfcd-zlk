# Electron 界面与文档阅读

## 进程职责

| 位置 | 负责什么 |
| --- | --- |
| `src/desktop/main.mjs` | 窗口、系统对话框、剪贴板、图片协议、文件保存、主题、受限 IPC |
| `src/desktop/preload.cjs` | 暴露窄接口，不把 Node 文件系统暴露给页面 |
| `src/desktop/worker.mjs` | 数据读取、字典、结构、合并、图库索引、文档查询 |
| `src/ui/app.js` | 页面切换、资料浏览和模块组织 |
| `src/ui/merge.js`、`rules.js` | 合并汇总与规则编辑 |
| `src/ui/gallery.js`、`images.js` | 图库操作与资料卡配图 |
| `src/ui/documents.js` | Markdown 阅读、目录、历史和搜索 |
| `src/ui/theme.js`、`workspace.css` | 主题、系统变化、布局和通用外观 |

页面按需加载模块，原始 JSON、统一资料、图片目录各有上下文和缓存。图片缺失不阻断文字资料；合并任务失败不替换当前版本。

## 使用体验约定

资料目录支持来源、类型、语言、物品类别的多选；类别内取并集、不同维度取交集。卡片列表精简、同一行多个；进入记录后仍以卡片展示字段和关系。官方根分组下的记录集合要展示记录卡片，不把整组当成单条详情。

浅色／暗色／跟随系统由 theme.js 在首屏应用，用户偏好记在本地；原生对话框使用相应主题。导航、侧栏、正文、弹窗和代码使用同一套变量。⌘ / Ctrl K 聚焦当前页面搜索。

## 文档从哪里读

`src/core/documents.mjs` 只登记：根 README、使用说明、`文档/**/*.md`、`工具/**/*.md`。大数据报告 JSON／TSV 保留在归档，通过源码／编辑器查看；阅读器不把它们当 Markdown 全文装载。

桌面版优先读取附近项目目录中的文档；离开完整项目运行时使用应用内随包保存的 Markdown。文档更新后可点击“刷新”，发布包需要重新打包才有新的内置副本。

## 阅读器功能

- 默认只列当前说明，按“总览、新人入门、深入理解、AI 协作、工具”分组；切到“全部”或“归档”可找历史。
- 搜索匹配标题、路径与正文，多个词一起筛选。
- 支持标题、段落、列表、代码块、表格、引用、行内代码和文档链接。
- 右侧章节目录跳转；文档链接在阅读器内打开，可返回上一文档；记住最后阅读的文档与字号。
- 一键复制完整 Markdown 或某个代码块，便于交给同事和其他 AI。
- 历史记录显示归档提示，提醒旧路径、数量和状态只适用于原版本。

Markdown 使用 DOM 文本节点渲染，不执行文档内 HTML 或脚本。外部 http／https 链接只在用户点击后交给系统浏览器；非 Markdown 的项目文件链接复制其相对路径，不授权任意本地文件读取。本文功能没有在本轮运行新的 UI 验收。

## 扩展入口时怎么改

前端页面、主进程白名单、preload 接口和 worker handler 要配套；不能只添加一个按钮。需要文件读取时先定义允许目录和键，再生成内容，避免把任意绝对路径当接口参数。

新增文档通常直接放入当前分类目录即可被阅读器登记，不必在源码再维护一份标题数组；长期重要入口仍应加入 `文档/README.md`。详见 [AI 交接](../AI/项目交接与修改边界.md)。
