# 工具运行与协作手册

## 环境和统一入口

维护脚本依赖完整项目，不是只解压应用 ZIP 就能执行。Node.js 版本要求见 `package.json.engines`（22.19+）；先安装锁定依赖。WFCD 准备和完整图片整理使用 Python 3。Windows 可用 `WORKBENCH_PYTHON` 指向 Python 可执行程序，值只放程序路径，不附加参数。

工具入口自动将工作目录定位到项目根目录，带空格和中文的路径作为参数传递，不拼成 shell 命令。你可以在任意当前目录调用入口。

```sh
node 工具/资料工具.mjs --help
node 工具/资料工具.mjs 3 --预览命令
```

不带任务时，终端会显示菜单；没有交互终端则只显示说明。每个任务分别运行，不会“顺手”下载或扫描整个图库。

## 命名任务

| 入口 | 参数和行为 |
| --- | --- |
| `01-获取数据.mjs` | 转交 CLI update；默认配置与 store 已指向项目，可以补 `--config` 等参数 |
| `02-处理数据.mjs` | 可追加位置参数 `资料根目录 输出报告路径`；默认扫原始 JSON，不扫图片 |
| `03-合并数据.mjs` | 支持 `--release`、`--rules`、`--overrides`、`--out`、`--profile full或pilot` |
| `04-获取WFCD图片.mjs` | 支持 `--archive 本地tar.gz`；`--refresh` 明确刷新最新上游，默认匹配本地快照 |
| `05-获取官方图片.mjs` | 读取离线官方 Manifest，下载／续传官方图；不会执行技能图临时下载支路 |
| `06-处理图片.mjs` | 支持 `--content`、`--archive`、`--official-cache`；会做大量哈希读取，不是每次启动必须运行 |
| `07-合成蓝图.mjs` | `--id` 必填，`--result-id` 可指定成品；`--out` 指 PNG，`--size` 范围 64～2048 |
| `08-启动工作台.mjs` | 调用项目 Electron；原始资料和图库共用项目现有文件 |
| `09-打包程序.mjs` | 构建两个 x64 ZIP 并保留当前／上一版；此入口不运行测试 |

详细实现位置见 [流水线脚本地图](00-数据与图片流水线脚本地图.md)。直接运行名字对应的 mjs 文件，或用总入口的中文命令／编号，效果相同。

## 本地原件与在线新快照

```sh
# 使用本地原件和导出的团队规则
node 工具/03-合并数据.mjs --rules ./团队规则.json

# 使用明确指定的在线快照
node 工具/03-合并数据.mjs --release 完整releaseId

# 仅预览获取命令，不联网
node 工具/01-获取数据.mjs --预览命令
```

示例中的“完整releaseId”需要替换为已有版本，不是可照抄的真实版本。获取完成后用 `node src/cli.mjs history --store .workbench` 查看列表。

## 早期原始资料工具

`工具/按快照重新获取.py`：按原始包 snapshot-manifest 重建到一个不存在的新目录。`工具/缓存WFCD无图片.py`：按固定 commit 获取 WFCD 文本树，明确排除图片。`工具/校验资料包.py`：读取已归档的原始文件校验清单做离线校验。三者保留原用途和命名，不自动嵌进新流程。

历史清单只证明对应日期的原始包，不能要求后续新来源文件仍与旧清单相同。工具支持的具体参数可读文件或显式 `--help`；本轮没有运行这些工具。

## 四人协作建议

1. 分类／字段同事维护 catalogs、fields 和未知字段清单；标明值的单位与适用类别。
2. 中文同事维护语言键、名称桥接和缺译证据；不根据英文相似猜物品身份。
3. 关系同事负责嵌套技能、组件、配方、奖励和强化／移植关系；每条规则给完整 ID 样例和源指针。
4. 工具同事负责图片索引、蓝图合成、UI 和文档；图像改动不得反向污染原始 JSON。

共同约定：提供来源 file、hash、pointer；规则变更写清影响的类别；缺失可以显式保留；不要覆盖别人的整份合同。由集成人合并团队规则，再构建同一输入上下文。程序内规则导出的 JSON 是交接格式，聊天里的名称描述不是可靠补丁。
