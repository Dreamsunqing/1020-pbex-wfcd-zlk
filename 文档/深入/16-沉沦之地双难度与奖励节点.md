## 展示和数据边界

沉沦之地改成两列：左普通，右钢铁之路；按第 1–21 层逐行对齐，同一层两张卡片等高，行距 12px。检查点、苦行加护与已核实说明直接留在卡片。总览预览前三层，进入详情看全部楼层；候选奖励点开独立弹窗，保留中文、图片、数量及已公布概率，关闭或 Esc 回到原位置。

原始 `Descents` 的六条记录是六个周时间窗，不是六种难度。当前仅筛选覆盖快照时间的排期；同一份楼层挑战用于左右对照。两列是难度展示与静态奖励规则投影，不声称官方接口下发了两份难度数据或玩家进度。不会将未来周当钢铁难度。

原始接口没有本周抽中物品、奖励表引用、领取状态或个人进度，`RandSeed` 的奖励生成算法也未核实。展示的是**候选池**，不能通过顺序、种子或概率声称某一候选是本周奖励。普通、钢铁的周奖励分别计算。

## 奖励层与检查点

层数依据：[DE 中文更新说明](https://www.warframe.com/zh-hans/patch-notes/pc/41-0-0)。两轨各有 10 个每周奖励节点。第 7、14 层单独标记检查点。

| 楼层 | 普通 | 钢铁之路 |
| --- | --- | --- |
| 2、9、16 | 常见资源候选 | 常见资源候选 |
| 4、11 | 常见资源候选 | 罕见候选 |
| 6、13 | 夜灵赋能 ×1 | 沉沦之地专属赋能 ×1 |
| 18 | 常见资源候选 | 钢铁精华 |
| 20 | 夜灵赋能，同种 ×3 | 专属赋能，同种 ×3 |
| 21 | 稀有候选 | 稀有候选 |

第 21 层另有罗瑟掉落，采用单独按钮和“可重复”标记，与每周层数奖励分开；不算作第 11 个周奖励，不与 21 层稀有池混抽。

## 官方掉落表与缺口

本次从 [DE 官方掉落表](https://www.warframe.com/droptables) 提取 8 张有明确沉沦之地标题的表：普通 20 层赋能；钢铁 6／13 层赋能、常见、罕见、稀有、钢铁精华、20 层赋能；罗瑟。记录原始英文表名、物品名、数量、页面公布的概率、来源锚点、页面 SHA-256 和获取时间。所有条目精确关联本地物品 ID；更新时若有歧义保留 `unresolved`，不按相似名字猜测。

- 普通常见／21 层稀有池在本次官方掉落表中没有单独列出，使用官方公告候选列表，不补写概率。
- 普通 6／13 层参考公告相同赋能类别与普通 20 层候选表，数量改为 1，**不沿用 20 层概率**；详情明确这一层派生依据。
- 普通常见热火核数量在官方中文和英文公告中不一致，因此不写死数量；只展示候选和“数量待核实”。钢铁数量采用本次官方掉落表的 75，而非旧中文公告的 250。
- 钢铁稀有池按掉落表采用泛用夜灵晶体蓝图与实际的全能 Forma，不把公告中列举的多个学派误拼成五份独立中奖项。加成类型同样服从掉落表中的资源掉落几率加成，不能替换成资源数量加成。
- 公布概率有四舍五入（如 27 × 3.70%），保留原值，不强制重归一，也不据此生成本周结果。
- 这些静态奖励来源目前仅核实国际服。国服仍显示本服排期与两列布局，并提示奖励规则待核实；不自动套用国际服候选池。

中文按完整 ID 读取本地字典和官方实体；无独立蓝图中文时，用配方明确的 `resultType` 对应中文派生“成品名 蓝图”。图片复用原图库，蓝图依然是底纹叠精确成品；不新增重复图片。未能本地化的名称保留来源英文供核对。

## 脚本和维护位置

| 文件 | 用途 |
| --- | --- |
| `工具/更新沉沦之地奖励.py` | 仅提取官方页面的沉沦之地表；校验已知表与概率，成功后原子替换缓存 |
| `src/data/live-state/descent-reward-tables.json` | 8 张官方掉落表、来源哈希与明确 ID |
| `src/data/live-state/descent-reward-rules.json` | 楼层到候选池、检查点、难度、普通缺表回退与来源限制 |
| `src/core/live-state/descent-rewards.mjs` | 只读解析候选池；不生成抽奖或进度 |
| `src/core/live-state/catalog.mjs` | 载入规则／表并加入证据哈希；关联本地物品和中文 |
| `src/core/live-state/view.mjs` | 当期排期 → 21 层 + 两种难度奖励信息 |
| `src/ui/live-state.js/.css` | 两列、逐层对齐、奖励弹窗和关闭返回 |

直接更新：

```sh
python3 工具/更新沉沦之地奖励.py
# 已有官方页面时可以离线提取：
python3 工具/更新沉沦之地奖励.py --html /absolute/path/droptables.html
```

此脚本需要本地 Plus 资料用于物品 ID 校对，只更新静态奖励缓存；不改原始 JSON、图库或周排期。楼层映射仍须对照官方说明维护，不能仅凭新表出现就猜测对应楼层。
