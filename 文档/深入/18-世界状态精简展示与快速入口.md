# 世界状态：模块精简、24 小时周期与快速入口

2026-10-24，基于 0.14.1 源码的本地后续调整。本文优先于第 13、15、16 章的旧界面描述；本轮提供本地提交及 Mac x64 解压版更新，不推送。

## 入口与使用

“世界状态”默认打开 **快速入口**，按实时、日常、周常、阶段性排列 20 个文字卡片。只提供导航，不混入总览里的默认内容卡。点击后进入本页详情，返回仍是快速入口。切到“总览”可查看图文卡片；任务、周常、商店、动态仍可分组查看。

| 维度 | 入口 |
| --- | --- |
| 实时 | 警报、裂缝、平原状态 |
| 日常 | 仲裁、钢铁之路每日突袭、集团任务、赏金任务、每日突击、电波任务、每日特惠、限时商店 |
| 周常 | 科研、沉沦之地、1999 日历、宝库奖励、双衍回廊、Teshin 周商品、活化战甲 |
| 阶段性 | 虚空商人、Prime 重生 |

这里的维度是用户指定的导航分类，不更改事件的实际重置周期。例如电波入口仍保留每日及每周挑战。原总览里的执刑官猎杀等模块继续可用。

### 复用推算实验室

没有独立世界状态卡片的四个入口直接调用现有桌面 API，不复制一套算法：

| 快速入口 | 现有 API / 源码 | 查询内容 |
| --- | --- | --- |
| 仲裁 | `arbitration` / `src/core/oracle.mjs` | 未来 24 个小时，`browse.wf/arbys.txt` |
| 钢铁之路每日突袭 | `browseIncursions` / `src/core/browse.mjs` | 未来 7 天，每天 6 节点，基础等级 +100 |
| Teshin 周商品 | `browseWeekly` / `src/core/browse.mjs` | 未来 8 周，校验过的 `browse.wf/live.ts` 规则表 |
| 活化战甲 | `oracleOptions`、`invigorations` / `src/core/oracle.mjs` | 输入区分大小写的游戏名，可选 3 个上一周期战甲、本周/下周；展示三组战甲及加成 |

离线快照以快照时间查询，界面注明；不把过期快照包装成实时结果。排期超范围显示原错误，不延伸猜测。上述四类算法目前仅验证国际服，国服入口明确提示未验证，不借国际服排期。游戏名仅用于本地 CRC32 条件推算，不查询账号；缺少完整历史输入时明确显示条件推算。国服自身的公开模块及其回廊选项仍独立展示。

## 周期和任务

### 六张周期卡

点击地球、夜灵平原、魔胎之境、奥布山谷、扎里曼、双衍王境，弹出从当前快照参考时间起的 24 小时阶段表。每行含状态、日期和起止时间；跨日保留两端日期，首尾裁剪到查询窗。中间阶段连续、无重叠或缺口。当前周期锚点只接受覆盖快照时间的集团窗口；同 Tag 多个未来记录不会误取首条，重叠且边界矛盾时拒绝推算。

`presentation.mjs::cycleTimeline` 复用 `normalizers/cycles.mjs` 的当前状态与时间锚，阶段长度分别为地球 4h/4h、平原与魔胎 100min/50min、山谷 400s/1200s、扎里曼 150min/150min、双衍每阶段 2h。它是规则推算，不能保证上游未来不调整。

### 快照统计

“此刻，始源星系”同行按任务、周常、商店分组，提供 14 个可点击统计。裂缝分始源／钢铁／九重天，警报和入侵按任务计数；赏金汇总全部地区内的任务条目，不以地区数量代替。科研汇总任务步数，日历按有奖励的游戏日计数，沉沦按楼层计数；商人按库存商品计数，限时商品和每日特惠按商品条目计数。所有数量基于完整快照，不受预览三项、搜索和当前筛选影响；点击直接进入对应模块，裂缝统计同时定位难度。缺失模块记为 0，不推测未知库存。纯投影函数为 `presentation.mjs::worldStatistics`。

### 虚空裂缝

模式按钮独占首行，星球／任务类型／纪元 picker 位于下方独立筛选区，明确标签、选中边框、重置操作并兼容暗色主题。裂缝卡片以约 520px 为换列基准加长；节点、星球、任务徽章、纪元、模式和剩余时间保持同一行。极窄窗口仅在卡片内部横向滚动，保留完整文字且不撑宽页面。

- 总览按到期时间升序，只展示即将结束的 3 项。
- 详情完整列出，无分页；筛选可叠加始源/钢铁/九重天、星球、任务类型、纪元，支持清空。
- 模式用左侧蓝/橙/青色区分，同时保留文字；纪元及任务类型也有带文字的彩色徽章。
- 星球、任务类型取精确节点 `ExportRegions[Node]` 及字典；纪元沿用裂缝 Modifier/Tier。文字与颜色同时表达分类。

### 突击、猎杀、警报与入侵

突击与执刑官猎杀默认折叠候选奖励，通过独立原生 dialog 查看，不改变背景模块尺寸。执刑官用 Boss 键精确关联 Amar/Boreal/Nira 源力石图片；突击不再显示修改说明的圆圈 i。警报最多预览 3 项，超过 3 项提供“完整内容”。

入侵不显示原始 Goal/Count，显示双方派系奖励与比例条；Corpus 蓝、Grineer 橙、Infestation 红，同时有派系文字与可访问比例标签。普通双方比例为 `50 + 50×Count/Goal`；Infestation 攻方剩余比例为 `100 + 100×Count/Goal`，均裁剪到 0–100。Goal 缺失/无效不画伪进度。

### 集团任务与赏金

六集团各一列，宽窗口一行排列；窄窗口横向滚动，每集团内部三个任务竖排。每个集团可独立选 1–5 级，选择只存本地，不声称读取了账号等级。

公开 `SyndicateMissions.Nodes` 为 7 个节点：等级 r 取第 r、r+1、r+2 项。等级 1 对应 1–3，等级 5 对应 5–7。依据为 [DE Specters of the Rail 更新说明](https://www.warframe.com/de/patch-notes/pc/18-16-0) 的任务合并规则。高档任务声望更高，但当前公开世界状态和 Plus 集团资料没有精确任务声望奖励字段，因此只标任务档位，具体声望数值不编造。`ExportSyndicates.titles` 提供等级中文名。

赏金“地区任务”改为“平原内可接取”；魔胎之境当前 `Jobs[6..8]`（第 7–9 项）显示“隔离库任务 I/II/III”。任务 ID、奖励表和来源保留不变。挑战/地区任务、奖励档位、表和池继续在独立弹窗中选择，详见 [第 17 章](17-世界状态赏金与奖励池.md)。

## 周常展示

- **回廊**：本周可选紧凑横排；钢铁奖励以 `ExportResources` 的精确 IncarnonAdapters 实体取灵化之源图片。关联缺失时不伪用武器原图。当前服的完整选项集合匹配 `browse.wf/live.ts` 中规则组，显示第几轮/总轮次，并推算后 3 周。匹配不唯一或来源缺失时保留当前公开奖励，不编造轮次。参考了旧 App `VUE/common/components/DuviriCycle.vue` 的分组识别思路；旧文件只有较早的武器组和国服偏移，不复制其旧偏移，使用当前校验后的规则表与两服各自公开选项。
- **科研**：读取每任务 `difficulties` 的 `CD_NORMAL` 和 `CD_HARD`，任务变体、共同风险、精英新增风险分开。精英新增项用橙色与“精英追加风险”文字双重标识，不把所有风险混称普通模式。详情保留中文说明。
- **1999 日历**：概览只展示奖励日；详情保留挑战、奖励、强化分组，组内等宽等高。
- **沉沦之地**：普通/钢铁任务相同，详情每层一张任务卡；卡内并列普通与钢铁独立候选奖励按钮，罗瑟掉落只出现一次。概览只列含奖励节点的楼层和奖励入口，不重复展示任务说明。奖励规则未验证的服务器提示待核实。两轨各 10 次、三倍赋能及候选概率等语义保持不变，详见 [第 16 章](16-沉沦之地双难度与奖励节点.md)。

## 商店与动态

| 模块 | 概览 | 详情与货币 |
| --- | --- | --- |
| 虚空商人 | 商品数、到离场时间 | 全宽图片卡；`Ducats`=杜卡德金币、`RegularCredits`=现金 |
| Prime 重生 / 瓦奇娅 | 当前重生角色名称，不显示消耗 | 首行完整组合包，其次本期、常驻商品；`PrimePrice`=御品阿耶、`RegularPrice`=阿耶精华 |
| 限时商店 | 精简商品预览 | 同款完整图片网格，无分页；`PremiumOverride`=白金、`RegularOverride`=现金，包括 1 现金商品 |

图片卡上图下文，描述和兑换所需仅在鼠标悬停或键盘聚焦时显示。缺图片不阻断商品；未来商人的旧 Manifest 不冒充未来清单。重生名称从单体 Prime 组合包提取并去重，兼容多角色，过滤“双重”及 DualPack；名称映射仍经现有字典。没有覆盖价格时只注明白金原价待查询，**缺字段不等于 1 现金或免费**。

活动放在周期条下的第一模块。新闻放在 Hero，3 条一组，每 9 秒切组，提供前后按钮；悬停或键盘聚焦 Hero 时暂停自动轮播。精选氏族只展示 `FeaturedGuilds`，样本 10 个全部可见；不混入中枢目标和 PVP 挑战。“特殊节点”和“商店精选”不再出现在界面，原始缓存、解析器和诊断不删除。

## 维护位置与回归

- `src/core/live-state/presentation.mjs`：周期时间窗、价格、重生名称、集团等级窗口及入侵比例；纯函数，可在浏览器与 Node 共用。
- `catalog.mjs`：字典、当前轮换规则与灵化之源 ID 关联。
- `normalizers/commerce-fields.mjs`：新增 RegularOverride DTO，保留未知字段。
- `view.mjs`：各模块投影与概览参数；`bounties.mjs`：赏金显示命名。
- `src/ui/live-state.js`、`.css`：快速入口、详情、筛选、dialog、轮播及深浅主题。
- `test/live-state-presentation.test.mjs`：跨日连续时间窗、价格 0/1/缺字段、组合包去重、多等级任务窗口、科研普通/精英、轮次及图片 ID。
- `scripts/check-world-state-ui.mjs`：独立临时配置的 Electron 回归。`WORKBENCH_UI_OFFLINE=1 node scripts/check-world-state-ui.mjs` 不刷新外网、不改真实用户配置；报告和截图在忽略目录 `artifacts/world-state-ui/`。常规运行也支持联网刷新分支。

`npm test`、`npm run check` 验证源码；UI 脚本检查筛选、弹窗、轮次、20 个快速入口、完整动态商品列表（数量来自当前投影，不写死）、深浅色、800px 窗口及双服隔离。本次未全量重下载图库，未改源图，未打包或发布。
