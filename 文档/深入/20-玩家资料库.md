# 玩家资料库

更新：2026-10-24，0.15.0。

## 使用入口

“世界状态”之后的“资料库”用于玩家查阅：分类、中文／英文搜索、图片卡片、物品详情。开发维护仍使用“资料浏览、合并汇总、合并规则”。随程序附带精简离线快照，首次打开即可浏览，不自动触发全量构建，也不联网下载数据或图片。当前目录存在不同版本的已构建资料时使用该版本。预构建和卡面实现见 [Mod、赋能与内置资料](21-Mod赋能卡面拼图与内置资料.md)。

十二个分类：战甲与机甲、武器、宠物与同伴、Mod 与套装、赋能、资源与部件、蓝图、虚空遗物、装备与道具、外观、生态与敌人、星系与成长。分类数字取当前构建中可展示的实体数量；沿用内部定义隐藏规则，实体不从构建中删除。

搜索作用于当前分类的全部已构建语言名称和描述；切换分类清空搜索与筛选。语言选项来自构建清单，只控制资料内容，页面操作文字仍为中文。缺失译文回退英文，不把英文伪装为译文。

## 筛选逻辑

- 装备分类、类型、触发方式、版本、稀有度、交易状态根据当前分类实际值提供。仅一种且未选中的条件隐藏。
- 不同条件取交集；每个选择器的数量在忽略自身条件、应用其余条件后计算。不能把其他条件过滤掉的选项数量当作全量数量。

- 武器可按名称、段位、基础伤害、基础暴击率和射速排序；数字排序把缺失值放末尾，相同值以 ID 保持稳定。

- 返回列表保留筛选、已加载卡片及滚动位置；关联跳转可回上一物品。切换资料目录／快照使旧请求失效。

## 内容与关系

详情优先展示中文说明、基础属性、被动、技能、显赫武器、强化 Mod、配方组件和材料。关系来自已构建的完整 ID 关联，不用名称猜测；关系卡片不展示 `/Lotus/...`。技能有中文说明、可移植标记，并可进入技能详情查询强化 Mod。较长的关联列表每次渲染 18 项。

Mod 等级效果使用现有嵌套语言投影，默认展示最高等级，可拖动查看其他等级。不能把缺失等级效果编造成中文；无结构化说明时保留已有描述。武器攻击模式独立展示，不能将不同模式伤害相加；模式中的暴击／触发百分数与基础面板比例值分别格式化。

遗物优先用 `attributes.relicRewards` 的 `rewardName`、`itemCount` 获取物品和数量。仅对已知 `/Lotus/StoreItems/` 前缀使用项目现有 `storeItemId()` 转换；再按完整 ID 寻找实体。官方列表缺失时回退 WFCD `attributes.rewards[].item.uniqueName`；有同 ID 的 WFCD `chance` 时保留其百分数，不跨精炼等级重新推算，不从“2X”名称猜数量。未能关联的条目暂不生成可点击的虚假物品。遗物现有上游列表未必完整，页面不表示全部实战掉落。

## 雷达图含义

雷达图在详情侧栏，精确数值在主栏。只适用于战甲、武器和同伴。比较集合要求相同实体类别、`attributes.category` 和 `attributes.type`，避免把近战、步枪、Archwing、战甲等混为一组。

每轴使用同类非缺失基础数值的分位：`(严格小于当前值的样本数 + 等值样本数 / 2) / 样本总数`。该轴至少 5 个样本且有差异才参与；至少 3 轴才能绘图。0 是有效数值，缺失不补 0。旁边列出每轴分位和样本量。分位不代表实战强度，不做 DPS 或配装评分；高射速并不被解释成整体更强。

## 图片与文本

复用 `imageDescriptors()`、`decorateImages()` 与本地共享图库。蓝图和 Tau 源力石继续按已维护的图层规则叠加；无图保留文字及轻量占位符。装饰图取当前列表前三项，局限于顶部小区域；物品图不会覆盖描述。英雄区和卡片使用真实物品图，不增加图库副本。

所有名称和描述复用 `plainGameText()`／`renderGameText()`。中文名称、嵌套效果和文本图标继续使用统一中间件；不执行描述中的 HTML。尚未有值的 `|DAMAGE|` 等参数保持原始表达，不猜测数值。

## 代码与接口

| 文件 | 责任 |
| --- | --- |
| `src/core/player-library.mjs` | 只读玩家投影、分类、联动筛选、排序、语言投影、关联与雷达分位 |
| `src/desktop/worker.mjs` | `playerLibraryStatus`／`playerLibraryList`／`playerLibraryDetail`，复用已构建资料或内置快照 |
| `src/desktop/main.mjs` | 三个只读方法进入 IPC 白名单 |
| `src/ui/player-library.js` | 浏览／详情、关联导航、按需图片、请求隔离 |
| `src/ui/player-library.css` | 玩家页面样式、深浅主题和窄窗口布局 |
| `src/ui/index.html`、`app.js` | 新入口、语言／搜索控件、目录切换重置 |

请求沿用 `datasetVersion` 校验。后端 WeakMap 缓存只绑定当前输出对象，目录或构建变化不能混用实体、图片和语言。详情只输出有玩家含义的字段，不返回开发溯源／候选字段。不修改已构建文件；发布时单独生成精简快照，不复制全量报告。
