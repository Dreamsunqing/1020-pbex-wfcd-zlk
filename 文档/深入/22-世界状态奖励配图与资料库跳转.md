# 世界状态奖励配图与资料库跳转

更新：2026-10-24，0.15.1。上一批资料库、Mod／赋能拼图和内置资料为 0.15.0。

## 修复内容

世界状态原先使用独立字典解析名称和图片，未读取 P3 合并后的图片描述符。加成类还存在第二个问题：通用加成 ID 没有官方图片 Manifest 记录，图库里有图的是带时长的商品 ID。因此只填 `AffinityBooster.png` 文件名仍找不到图，不能把“描述符有文件名”当成配图成功。

现在在后台构造世界状态视图后，调用 `enrichWorldRewardArt(view, dataset)`，为可精确关联的奖励、嵌套奖励池和商店商品接入资料库图片、蓝图成品、Mod／赋能拼图元数据和资料关联。整个过程只修改归一化视图，不修改世界状态快照或 P3 数据。

## ID、配图和名称边界

- 优先完整 ID，`/Lotus/StoreItems/` 只按现有契约转换。已经给出但未能解析的路径不靠相似名称替换。
- 没有路径 ID 的名称只允许全名唯一匹配；同名物品有多个 ID 时保留原文，不生成猜测链接。
- 接上 P3 的 `imageName`、`icon`、配方 `resultId/resultImageName` 和 `cardArt`。已知源力石与蓝图继续原有叠层；普通 Forma 继续显式选用 Forma.png。
- 已精确关联但还在显示英文名称时，可使用该实体的现有中文名称；不会更改奖励数量、概率、难度或时长。
- 现金奖励使用程序已有的 `<CREDITS>` 真正文本图标；不编造货币实体跳转。
- 全服加成只使用现金／资源／经验的对应图示，不连接到个人加成商品，避免把全服活动误解为可购买的物品。

## 交互

可关联的奖励卡支持点击、Enter、空格进入资料库；商品卡保留悬停价格与描述，另有“资料库 →”按钮。弹窗在成功进入后关闭，详情有“← 世界状态”返回原页面；保留世界状态的模块、筛选与位置，不把详情插入赏金模块而挤坏布局。没有实体的条目保持普通文字卡。

`libraryId` 与 `libraryVersion` 随视图返回；跳转检查当前资料版本。若资料构建已变化，提示刷新世界状态，不把过期奖励指向不同版本。无需玩家手动构建，内置快照仍可承接奖励详情。

## 本轮实际抽查结果

打包版使用空白用户目录、已有本地图库及当前国际服样本：6969 处关联出现对应 587 个唯一实体。分类型选取 32 项实际取图，30 项可用，包括通用加成、蓝图、Mod／赋能和源力石；2 项暂缺：

| 奖励 | 现有资料中的图标路径 |
| --- | --- |
| 赋能助力 | `/Lotus/Interface/Icons/Rewards/ArcaneGenericRareIcon128.png` |
| 赋能助力：双重组合 | `/Lotus/Interface/Icons/Rewards/ArcaneGenericRareDoubleIcon128.png` |

两个 ID 分别为 `/Lotus/Types/BoosterPacks/CalendarArtifactPack`、`/Lotus/Types/BoosterPacks/CalendarMajorArtifactPack`。本机官方 Manifest 和已下载图片索引没有对应条目，WFCD 也未解析到图；保留文字与资料库链接，不拿单个赋能图标冒充奖励包。后续取得上述真实文件后接入现有索引即可，不需修改奖励数据。此抽查不是全图库完整性承诺。

验证：144 项单元测试；打包版 8 组资料库、22 组世界状态界面检查；额外通过无源 JSON／无合并缓存启动检查。Mac x64 解压版与 ZIP 内源码、预构建数据及版本一致。
